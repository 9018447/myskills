# 第2章: 精馏塔的分析

## 核心思想
在进入严格稳态/动态模拟之前，先用简化近似方法（图解法与解析法）理解各设计与操作参数如何影响分离：塔板数与回流比之间存在技术经济权衡，而这两种极限（$N_{\min}$ 与 $RR_{\min}$）是所有设计方法（包括 Aspen 严格计算）的基准锚点。

## 关键框架与原理
- **自由度分析（直观法）**: 在设计开始前确定必须指定的独立变量数。两产品塔的 5 个设计自由度是 $x_{D,HK}$、$x_{B,LK}$、$p$、$N_T$、$N_F$（或 $D$、$RR$、$p$、$N_T$、$N_F$）；给定产品纯度与压力后仅剩 2 个自由度。用避免对成百上千方程做严格变量计数的"直观法"。
- **McCabe-Thiele 图解法（二元）**: 仅限二元体系，但结论可外推至多元。用于直观演示 VLE 曲线、回流比、进料热状况对塔板数的影响；求理论板数用逐板法（阶梯法）。
- **Fenske 方程**: 求全回流下的最少塔板数 $N_{\min}$，适用于多元体系（假设恒定相对挥发度），用于快速估算分离难度的下限。
- **Underwood 方程**: 求多元体系的最小回流比 $RR_{\min}$（恒定相对挥发度假设），两步求解：先解 $\theta$（取 $\alpha_{LK}$ 与 $\alpha_{HK}$ 之间的根），再直接代回得 $RR_{\min}$。
- **$q$ 线（进料热状况线）**: 联系精馏/提馏两操作线交点与进料组成，斜率 $-q/(1-q)$，由等温闪蒸算出的进料液相分率 $q$ 决定。

## 关键概念
- **轻/重关键组分 (LK/HK)**: 设计中规定其纯度指标的两组分——LK 在塔底受控，HK 在塔顶受控。
- **恒摩尔流假设**: McCabe-Thiele 的前提，塔段内液相/汽相摩尔流量各自恒定（$L_R = R$，$V_R = R+D$）。
- **q 值（进料热状况）**: 进料中液相摩尔分率，由进料温度/压力/组成的等温闪蒸计算；饱和液体 $q=1$（q 线垂直），饱和蒸气 $q=0$（q 线水平）。
- **夹点 (pinch)**: 操作线与 $q$ 线的交点落在 VLE 曲线上的条件，跨越该点需无穷多塔板，对应最小回流比。
- **$N_{\min}$（最少塔板数）**: 全回流操作（$D=0$，$RR\to\infty$，操作线退化为 45° 对角线）时所需板数。
- **$RR_{\min}$（最小回流比）**: 无穷多塔板下的极限回流比，由夹点条件下的操作线斜率反算。
- **操作线 (ROL/SOL)**: 塔段内 $y$–$x$ 关系，斜率分别为 $L_R/V_R$ 与 $L_S/V_S$，各自与对角线交于 $x_D$、$x_B$。
- **理论板**: 汽液达到平衡的级；逐板法中每一步"垂直到 VLE 曲线、水平到操作线"代表一块。

## Aspen 操作要点
本章为手算/图解方法章，作者未走 Aspen 对话框流程。其与 Aspen 的衔接点是：
1. 相对挥发度 $\alpha_{LK,HK}$ 是 Fenske/Underwood 的输入——用 Aspen Plus 的物性分析（Tools → Analysis → Property → Binary/Generic）获取所选物性方法下各组分的 $\alpha_j$。
2. Fenske + Underwood 的组合即 Aspen 捷算塔 DSTWU 内置的 FUG 核心体系；本章手算结果应与第4章的严格精馏（RadFrac）结果对比验证。
3. $q$ 值可由 Aspen 闪蒸（Flash2）模块或物性环境对进料做等温闪蒸得到。

## 公式与方程
物料衡算求 D：
$$zF = Dx_D + Bx_B \;\Rightarrow\; D = F\frac{z - x_B}{x_D - x_B}$$

精馏段操作线（ROL）斜率：
$$\frac{L_R}{V_R} = \frac{R}{R+D} = \frac{RR}{1+RR}$$

提馏段流量（q 定义）：
$$q = \frac{L_S - L_R}{F} \Rightarrow L_S = qF + L_R,\quad V_S = L_S - B$$

q 线方程（斜率 $-q/(1-q)$，过对角线上的 $z$ 点）：
$$y_{int} = \frac{-q}{1-q}x_{int} + \frac{z}{1-q}$$

Fenske 方程：
$$N_{\min} + 1 = \frac{\lg\left[\left(x_{D,LK}/x_{D,HK}\right)\left(x_{B,HK}/x_{B,LK}\right)\right]}{\lg\left(\alpha_{LK,HK}\right)}$$

Underwood 方程组：
$$\sum_{j=1}^{NC}\frac{\alpha_j z_j}{\alpha_j - \theta} = 1 - q, \qquad \sum_{j=1}^{NC}\frac{\alpha_j x_{Dj}}{\alpha_j - \theta} = 1 - RR_{\min}$$

## 反模式
- **对巨大方程组做严格自由度计数**: 变量与方程都是成百上千，两个大数相减，任何统计差错被显著放大——用 5 自由度直观法。
- **脱离 $N_{\min}$/$RR_{\min}$ 极限直接选设计点**: 不先算两个极限，就无法判断所选 ($N_T$, $RR$) 离经济区多远。
- **把二元图解结论误当成只适用于二元**: 作者明确指出各参数作用可外推至多元体系，不应因方法受限而丢弃其洞察。
- **假设提高产品纯度需要大幅提高回流比**: 错——纯度提高主要增加所需塔板数，对回流比影响不显著。
- **Underwood 取任意 θ 根**: θ 多项式有 NC 个根，必须取介于 $\alpha_{LK}$ 和 $\alpha_{HK}$ 之间的那个根。

本章以假设二元塔贯穿做图解演示（图2.1–2.10），无具体数值体系：已知 $F$、$z$、规定 $x_D$、$x_B$ → 物料衡算得 $D$、$B$ → 定压下绘 VLE 曲线与 45° 对角线 → 定 $RR$ 画 ROL → 由 $q$ 画 q 线 → 过 $x_B$ 连交点画 SOL → 从 $x_B$ 起逐板阶梯（垂直到 VLE、水平到操作线），跨过操作线交点处即进料板，跨过 $x_D$ 得总板数。两个极限用同一张图演示：全回流时操作线=对角线，对角线与 VLE 之间作阶梯得 $N_{\min}$（图2.8）；操作线-q线交点触到 VLE 曲线即夹点，反推 $RR_{\min}$（图2.9）。数值算例由第4章（Fenske/Underwood 与严格法对比）给出。

## 关键要点
1. 两产品塔设计自由度 = 5；给定产品纯度和压力后仅剩 2 个待定，通常选 ($N_T$, $RR$) 或 ($D$, $RR$)。
2. 任何设计前先算 $N_{\min}$（Fenske/全回流）和 $RR_{\min}$（Underwood/夹点），这两个极限框定所有可行设计。
3. 塔板数与回流比是权衡关系（图2.10）：多板可省能量，多回流可省塔高——最佳点需结合技术经济与动态控制性能共同决定。
4. VLE 曲线越"胖"（$\alpha$ 越大）分离越易 → 板数少、回流低、能耗小。
5. 提高产品纯度的代价主要是增加塔板数，而非回流比。
6. 提高塔段内的液/汽比会增强该段的分离效果。
7. Underwood 求 θ 时只取 $\alpha_{LK}$ 与 $\alpha_{HK}$ 之间的根；Fenske/Underwood 均假设恒定相对挥发度。
