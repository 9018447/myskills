# 第4章: 精馏的经济优化

## 核心思想
设计问题=在给定进料/产品规格下找**最优理论板数**；校核问题=板数固定的塔找**最优操作条件**（如最大化利润的釜液纯度）。两条路线：启发式（N=2N_min、RR=1.2RR_min）与严格法（扫板数、算 TAC 取最小）。启发式给出偏保守但工程上稳妥的设计；TAC 曲线通常很平坦，优化收益有限但方向明确——能耗成本主导一切。

## 关键框架与原理
- **TAC 总年成本法**: 严格经济优化的目标函数。TAC = 设备投资/回收期(3年) + 年能耗费。扫总板数 NT（进料板按比例同步移动），对每个 NT 收敛严格模拟 → 算塔径、换热面积、投资、能耗 → 画 TAC-NT 曲线取最低点。适用于设计阶段的板数/压力优化。
- **启发式 1（N = 2N_min + 2）**: 快速定板数。N_min 由严格模拟（RR→∞）或 Fenske 方程求得；+2 对应回流罐与再沸器两块"板"。
- **启发式 2（RR = 1.2 RR_min）**: 快速定回流比。RR_min 由严格模拟或 Underwood 方程求得。注意：**两种启发式不能同时使用**——任选其一即完全确定设计。
- **Fenske 方程**: 恒定相对挥发度体系求 N_min。需先取塔顶（第2板）与再沸器两端的相对挥发度，取**几何平均** α_avg=√(α_top·α_reb)。
- **Underwood 方程组**: 恒 α 体系求 RR_min。第一式解 θ（落在 α_H 与 α_L 之间），第二式代 θ 求 RR_min。q 为进料热状态（饱和液 q=1）。
- **校核问题优化（操作最优化）**: 板数固定，用两组 Design Spec/Vary（馏出组成恒定 + 釜液组成作为扫描变量），对每个 x_B 算利润 = 产品收入 − 进料成本 − 能耗，找最大点；或直接用 Aspen Optimization 模块（NLP/SQP）自动求解。
- **真空塔压力优化**: 压力↓→相对挥发度↑、Q_R↓、可用更便宜低压蒸汽；但蒸汽密度↓→塔径↑、冷凝温差↓→换热面积↑。扫压力算 TAC 取平衡点。

## 关键概念
- **TAC (Total Annual Cost)**: 年能耗费用与年化设备投资之和，单位美元/年；精馏设计优化的常用目标函数。
- **回收期 (payback period)**: 设备投资折算为年度成本的除数，本书取 3 年。
- **相对挥发度 α**: (y_L/x_L)/(y_H/x_H)，衡量分离难易；变 α 体系取塔顶/塔底值的几何平均。
- **N_min 最少理论板数**: 全回流下达到规定分离所需板数（Fenske）。
- **RR_min 最小回流比**: 达到规定分离所需回流的下限（Underwood），无穷板数下操作。
- **设计问题 vs 校核问题**: 前者定设备结构（板数、直径），后者定操作变量（纯度、回流比）。
- **NLP 非线性规划**: 校核优化的数学本质，Aspen 用 SQP（序贯二次规划）算法求解。
- **净现值/贴现现金流量**: 更精细的经济目标函数，但需大量不可靠预测假设，概念设计阶段少用。

## Aspen 操作要点
1. **查相对挥发度组成**: Data Browser → C1 模块 → Profile 子项，读第2板与再沸器（末板）的 x/y 摩尔分数，手工算 α 并取几何平均。
2. **Design Spec/Vary 扫釜液纯度**: 第一组 Design Spec/Vary 固定馏出物组成；第二组指定塔底组成，逐点改 x_B 重跑模拟，配合 Matlab/手算利润曲线。
3. **Optimization 模块（NLP 优化）**:
   - Data Browser → Model Analysis Tools → Optimization → 点 **New** → OK 接受新 ID。
   - **Define 页**: 输入变量名（如 FW/DW/BW 为物流质量流量 kg/s，QR 为再沸器热负荷 W）。选中行点 **Edit**：Category 选 **Streams**（Reference: Type=Stream-Var, 变量=F1, 具体量=Mass-Flow）；模块变量（QR）Category 选 **Blocks**。
   - **Objectives & Constraints 页**: 指定 PROFIT 为**最大化**目标。
   - **FORTRAN 页**: 输入目标函数表达式（如 PROFIT=DW*0.528+BW*0.264−FW*0.264−QR*4.7e-9）。
   - **Vary 页**: 右键空白 Variables 框 → **Create** → 选 C1 模块、变量 **MOLE-RR**，输入变化范围。
   - 点 **N（Next）** 运行；Control Panel 显示 **SQP 算法**与迭代次数（本例4次收敛）；结果在 C1 → **Results** 下查看。
4. **换热面积手算**: A=Q/(U·ΔT)，U、ΔT 取表4.1经验值（或按冷/热媒温度算对数平均温差，注意再沸器蒸汽侧压力因控制阀压降低于供汽压力）。

## 公式与方程
Fenske（二元，lg 可换 ln）:
$$N_{\min}+1=\frac{\lg\left(\dfrac{x_D}{1-x_D}\cdot\dfrac{1-x_B}{x_B}\right)}{\lg(\alpha_{avg})},\qquad \alpha_{avg}=\sqrt{\alpha_{top}\,\alpha_{reb}}$$

Underwood 两式（q=1 饱和液进料）:
$$\sum_{j=1}^{NC}\frac{\alpha_j z_j}{\alpha_j-\theta}=1-q,\qquad \sum_{j=1}^{NC}\frac{\alpha_j x_{D,j}}{\alpha_j-\theta}=1+RR_{\min}$$

换热面积与设备费用（A 单位 m²，D、L 单位 m）:
$$A_R=\frac{Q_R}{U_R\,\Delta T_R},\quad A_C=\frac{Q_C}{U_C\,\Delta T_C}\quad(U_C=0.852,\ \Delta T_C=13.9\,\mathrm{K};\ U_R=0.568,\ \Delta T_R=34.8\,\mathrm{K})$$
$$C_{hx}=7296\,(A_C^{0.65}+A_R^{0.65}),\qquad C_{shell}=17640\,D^{1.066}\,L^{0.802}$$

TAC 与能耗（本书案例 energy 价 \$4.7/GJ）:
$$TAC=\frac{C_{shell}+C_{hx}}{3}+Q_R\cdot c_{energy}\cdot 3600\cdot 24\cdot 365/1000$$

公用工程价：低压蒸汽(6 bar,433 K) \$7.78/GJ；中压(11 bar,457 K) \$8.22/GJ；高压(42 bar,527 K) \$9.88/GJ；电 \$16.8/GJ；冷水 \$4.43/GJ；-20℃ \$7.89/GJ；-50℃ \$13.11/GJ。

利润目标函数（Aspen FORTRAN 页，流量 kg/s，QR 单位 W）:
$$PROFIT=DW\cdot0.528+BW\cdot0.264-FW\cdot0.264-Q_R\cdot4.7\mathrm{e}{-9}$$

## 反模式
- **两种启发式同时用**: N=2N_min 已完全定下设计，再叠加 RR=1.2RR_min 会互相冲突（本例 2×N_min≈32 板对应 RR≈3.49≈1.2×RR_min 纯属巧合）。
- **把启发式当最优**: 本例启发式(32板)比最优(44板)贵约 5%，比值实为 N/N_min≈2.8、RR/RR_min≈1.04，说明"2 倍/1.2 倍"规则偏保守、非经济最优。
- **忽视 TAC 曲线平坦性**: 过度精调板数收益小；但能耗减半会使最优板数从 44 降到 42——能源价格假设比板数精调更重要。
- **表4.1温差当普适值**: 13.9 K / 34.8 K 只是近似；严格做应按实际公用工程与工艺温度算对数平均温差，并考虑控制阀压降对蒸汽饱和温度的影响。
- **忽视再沸器结垢**: 再沸器 U(0.568) 低于冷凝器(0.852)，因高温结焦聚合与重组分集中塔底；取冷凝器的 U 会低估再沸器面积。
- **真空塔一味降压**: 低压虽省能耗、可用低价蒸汽，但塔径（汽密度）与冷凝面积（温差）的设备费上升，须以 TAC 找平衡而非单向操作。

## 实例演练
**设计优化（脱丙烷塔，丙烷/异丁烷，xD=0.98, xB=0.01）**: 严格模拟 N_min=15、RR_min=2.9。扫 NT=24~48（进料板同步移动），TAC 在 **NT=44（进料板19，N/N_min=42/15=2.8，RR=3.0，RR/RR_min=1.04）** 时最小，为 **4.823×10⁶ 美元/年**；启发式 32 板塔 TAC=5.09×10⁶ 美元/年（能耗 4.03×10⁶ 占大头，壳体 1.4×10⁶、换热器 1.79×10⁶）。能耗价减半 → 最优板数 44→42，TAC 4.23→2.98×10⁶ 美元/年。材质更贵（非不锈钢）→ 最优板数下降。
**操作优化（同一塔，利润最大化）**: 变量=回流比（MOLE-RR），两组 Design Spec/Vary 保持馏出组成、扫描釜液丙烷含量。x_B 降至 0.2% 摩尔分数以下再沸器负荷骤增；**NLP/SQP 4 次迭代收敛，最优 x_B=0.2246%**，DW=18.05 kg/s、BW=34.46 kg/s、QR=27.17 MW、PROFIT=4.637 美元/s。
**真空塔压力优化（MMH 塔，馏出物 MH，常压沸点 392.2 K）**: 扫 0.2~0.6 atm，**0.4 atm 最优**（TAC=0.4842×10⁶ 美元/年）：塔釜 410 K 可用低压蒸汽（7.78 \$/GJ）、Q_R=0.9147 MW，代价是塔径 2.044 m 与冷凝面积 78.45 m² 增大；0.6 atm 时需中压蒸汽（TAC=0.4894×10⁶）。

## 关键要点
1. 设计优化主流程：严格模拟求 N_min、RR_min → 扫板数算 TAC → 取最低点；启发式仅作快速初值与校核。
2. Fenske 用 α 几何平均；Underwood 需先解 θ 再求 RR_min，两者仅适用于近恒 α 体系（本例 α=1.76~1.85）。
3. TAC = (壳体+换热器)/3 + 年能耗；壳体 ∝ D^1.066·L^0.802，换热器 ∝ A^0.65，小板数→高能耗/大塔径，大板数→高塔体费。
4. 能耗成本主宰设计：TAC 大头是能耗（本例 ~80%），能源价格假设直接移动最优点。
5. 校核问题用 Optimization 模块（Define→Objectives→FORTRAN→Vary，SQP 求解）或 Design Spec/Vary 扫描利润曲线。
6. 压力优化需权衡三效应：α 与蒸汽等级（降本）vs 塔径与冷凝温差（增本），一律以 TAC 判据定。
7. 保守设计（塔径、换热面积留裕量）是好实践：改板数便宜（可缩板间距），改塔径等于重做容器。

- **第3章**: 严格模拟基础——N_min、RR_min 的模拟求法，塔径/高度 sizing，32 板脱丙烷塔基准设计；本章经济参数直接套用其结果。
