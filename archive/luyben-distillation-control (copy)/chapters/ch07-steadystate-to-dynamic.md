# 第7章: 由稳态模拟转换为动态模拟

## 核心思想
稳态模拟不含设备尺寸，而动态响应由"流量与体积"共同决定——转换为动态模拟的本质是补齐设备几何（回流罐、塔釜、塔径）、修正好阀门与压力体系，然后在 Aspen Dynamics 中按"液位/流量先行、温度/组分后行"的顺序搭建控制器并用继电反馈测试整定。

## 关键框架与原理
- **设备定径启发式（5 min 停留时间准则）**: 回流罐以（馏出物+回流）体积流量、塔釜以进入再沸器的液体体积流量为基准，容器在 50% 充装量时持有 5 min 液体（即总体积 = 体积流量 × 60 s/min × 10 min）；长径比取 2，由 $V=(\pi D^2/4)(2D)$ 反算直径与长度。
- **压力一致性原则（Pressure Checker）**: 转换前进料阀出口压力必须精确等于进料板压力（从 Profiles 读取），否则 Aspen Dynamics 数值求解失败；用工具栏 Pressure Checker 按钮验证全管网压力兼容。
- **阀门有效相态原则**: 全液相选 Liquid-Only、全汽相选 Vapor-Only、入口泡点的减压阀选 Vapor-Liquid（阀内闪蒸）；选错是 Aspen Dynamics 数值问题的常见根源。
- **控制阀压降设计原则**: 设计工况下控制阀应承担足够压降（本章两阀均 3 atm，约 50% 开度），否则阀门饱和后丧失可调性——泵和阀在稳态中"非必需"，在动态中"至关重要"。
- **五回路基本控制结构**: 压力控制器（AD 自动生成）+ 回流罐液位 + 塔釜液位 + 进料流量 + 温度/组分控制器；回流量默认固定为质量流量常数，不作为独立被控变量。
- **死时间/滞后补偿框架**: 温度测量加 1 min 死时间、组分测量加 3 min 死时间（均为真实测量动态），使整定结果不虚优；死时间元件须在回路运行正常后再插入，避免初始化问题。
- **继电反馈 + Tyreus-Luyben 整定流程**: 闭环继电测试 → 得最终增益 $K_U$ 与最终周期 $P_U$ → TL 公式计算 → Update controller；对精馏塔尤其合适，因为过快响应会触发液泛/液漏的水力学极限。
- **比值/前馈框架**: R/F 比值（乘数器+流量控制器串级）、Q_R/F 前馈（乘数器输出叠加在温度控制器输出上）、回流比结构（低 R/R 用 D 控液位、高 R/R 用回流控液位）。

## 关键概念
- **Relay-feedback test（继电反馈测试）**: 在闭环中用继电器替代控制器使过程极限振荡，直接测出 $K_U$ 和 $P_U$ 的实验整定方法。
- **Ultimate gain / period（最终增益/最终周期）**: 极限振荡时对应的临界增益 $K_U$ 与振荡周期 $P_U$。
- **Tyreus-Luyben rules**: $K_C=K_U/3.2$，$\tau_I=2.2P_U$ 的保守整定规则，适合水力学受限的精馏塔。
- **Direct/Reverse action（正/反作用）**: PV 升 OP 升为正作用（Direct），PV 升 OP 降为反作用（Reverse）。
- **Dead time（死时间）**: 模拟温度/组分测量内在延迟的动态元件，插入在被控变量信号线上。
- **Cascade control（串级控制）**: 主控制器（组分）输出作为副控制器（温度）的设定值；副控制器投在 Cascade 模式。
- **Strip chart / Communication time**: AD 的实时趋势图；Communication time 只影响绘图密度（默认 0.01 h，可改 0.0005 h），不影响积分结果。
- **Rewind snapshot（恢复快照）**: 收敛稳态后保存 Initialization Run 快照并将时间归零，可随时回到同一初始条件。

## Aspen 操作要点
1. **定径输入**: C1 模块下 Profiles → Hydraulics 标签页读第 1 块板和塔底板体积流量；点工具栏 **Dynamics** 按钮（若无则 View → Toolbar 勾选 Dynamics）→ **Reflux Drum** 标签页输入直径/长度 → **Sump** 标签页同样操作 → **Hydraulics** 标签页输入塔板范围（2~31）与塔径（5.91 m）；堰高默认 0.05 m、板间距 0.6096 m。
2. **压力核对**: 把 V1 出口压力设为进料板压力（如 1709839.11 N/m²），重跑稳态，然后点 **Pressure Checker** 按钮。
3. **导出**: File → Export → 下拉列表选 "Pdriven Dyn Simulation" → Save，生成 .dynf 与 .dyn.appdf 两个文件。报"压降太小"错误时**降低堰高**（0.05→0.025 m）而非改压降，因为堰高不影响稳态结果；随后会提示"进入 AD 后立即设置液位控制器"。
4. **首次运行**: 双击 .dynf 打开 → 运行模式下拉菜单选 **Initialization** → Run 确认无误 → 切回 **Dynamic** → Run（看消息窗绿色方块，变红即出错）。
5. **建液位控制器（LC11 例）**: Exploring 窗口 → Simulation → Dynamics → Control Models，把 **PIDIncr** 拖入流程图 → 右击 Rename；从 Stream Types 拖 **Control Signal**，PV 连塔板 Level（第 32 块板），信号另一端接 LC11.PV；OP 信号接 LC11.OP → 阀 V11。双击图标开仪表面板 → **Configure** → **Initialize Values**（得稳态液位 6.35 m、Bias=50%）→ 动作选 **Direct**，纯比例 K_C=2、积分时间 9999 min → **Ranges** 页确认液位变送器 0~12.7 m、输出 0~100%。
6. **压力控制器检查**: AD 自动生成，默认增益 20、积分 12 min，输出是冷凝器移热速率（范围 −45347000~0 W，移热为负）故为反作用；通常只需把压力变送器量程改为更窄（如 14~19 atm）并相应减增益。
7. **流量控制器**: PV 接进料摩尔流量、OP 接 V1；**最常见的错误是忘记设为反作用（Reverse）**；常规流量整定 K_C=0.5、积分时间 0.3 min。
8. **温度控制器（TC9 例）**: PV 取第 9 板温度（337.36 K，选温度分布陡峭处）、OP 取 QRebR；反作用；Ranges 由默认 273~401 K 改窄为 320~370 K。先不带死时间跑通回路，再右击温度信号线 → **Reconnect Destination** 接入 Dead_time 元件（右击 → Forms → All Variables 设死时间 1 min），运行 Initialization 使输入/输出显示实际值。
9. **继电反馈测试**: 双击控制器 → **Tune** 按钮 → 闭环测试，Relay output amplitude 默认 5%（高非线性塔应减小）→ Run → **Start test** → 振荡 5~6 个循环后 **Finish test**（得 $K_U$=5.9、$P_U$=4.5 min）→ **Tuning parameters** 标签页选 Tyreus-Luyben → **Calculate**（K_C=1.84、τ_I=9.9 min）→ **Update controller**。绘图太密时 Run → Run Options → Communication time 改 0.0005 h。
10. **保存与快照**: Tools → **Capture screen layout** 保存仪表面板布置；每次加完控制器都试运行一段；收敛后存文件、Rewind（工具栏右起第 5 个按钮）选 Initialization Run 快照保存，Sim Time=0。
11. **R/F 比值**: 乘数器输入1=进料摩尔流量、输入2=R/F=1.392、输出接回流流量控制器 SP（该控制器 PV/SP 用摩尔流量 F 而非质量流量 Fm、OP 用质量流量，切 **Cascade**）。
12. **Q_R/F 前馈**: 乘数器输入1=进料摩尔流量、输入2=Q_R/F 比值（单位必须是 GJ/kmol：97.799 GJ/h ÷ 3600 kmol/h = 0.02717 GJ/kmol）、输出送温度控制器；安装后温度控制器重新整定（K_C=1.96、τ_I=11.9 min）。
13. **组分控制器**: PIDIncr，PV=馏出物异丁烷摩尔分数、OP=QRebR，量程 0~0.05 摩尔分数；跑通后插 3 min 死时间再测（得 $K_U$=0.547、$P_U$=33.6 min）。
14. **串级 CC-TC**: 组分控制器输出接 TC 的 SP，TC 切 Cascade；组分控制器重新整定（$K_U$=0.98、$P_U$=15.9 min，比直接控制的 0.58/32.4 min 紧凑）。
15. **画图**: Tools → New Form → Plot 命名（如 results）→ 把变量从 Forms/Results 表拖入图窗；右击图 → Properties → Axis Map 页勾 One for Each 分轴；右击 → **Show History** 导出数据表，复制到 Matlab 绘图比较。

## 公式与方程
- 容器总体积（50% 充装含 5 min 停留时间）：
$$V_{tot} = F_{vol} \times 60 \times 10 \ \mathrm{m^3}$$
- 长径比 2 的筒体：
$$V = \frac{\pi D^2}{4} \times (2D)$$
  回流罐 D=4.08 m、L=8.16 m；塔釜 D=5.08 m、L=10.16 m。
- Tyreus-Luyben 整定规则：
$$K_C = \frac{K_U}{3.2}, \qquad \tau_I = 2.2\, P_U$$
- 比值器常数（热量/流量比必须用 GJ/kmol）：
$$\frac{97.799\ \mathrm{GJ/h}}{3600\ \mathrm{kmol/h}} = 0.02717\ \mathrm{GJ/kmol}$$

## 反模式
- **死时间与控制器同时初次安装**: 易引发初始化问题——应先让无死时间回路运行正常，再插入死时间元件并跑 Initialization。
- **乘数器输出直接接控制阀**: 回流比结构中应接到馏出物流量控制器的 SP（串级），直连阀门是"常见且严重的模拟错误"。
- **流量控制器忘记设反作用**: 设置流量控制器最常见的错误。
- **导出报压降过小却去改压降**: 会破坏稳态；正确做法是减小堰高（0.05→0.025 m），稳态结果不受影响。
- **忽视控制器初始化 bug**: AD 有时把 OP 初始化为 100% 而非 50%、或 PV 偏离稳态值；解法是切手动输入正确 OP、运行一段时间后回自动。
- **不保存、不留快照**: 不遵守 Silebi 第一模拟定律（及时保存）会丢失工作；收敛稳态后须存文件并 Rewind 到 Sim Time=0 的快照。
- **不缩小变送器量程**: 温度默认量程 273~401 K 太宽，降低分辨率；应改为窄量程（320~370 K）并相应调整增益。

## 实例演练
丙烷/异丁烷塔（32 块理论板、进料第 14 板、16.8 atm、xD 杂质 iC4=2%、xB 杂质 C3=1%）。定径后导出 AD，装 5 个基本回路并整定：TC9 继电测试得 K_U=5.9、P_U=4.5 min → K_C=1.84、τ_I=9.9 min；组分控制器 K_U=0.547、P_U=33.6 min；CC-TC 串级中组分控制器 K_U=0.98、P_U=15.9 min（明显更紧凑）。扰动测试：进料 +20%（0.5 h 时 1→1.2 kmol/s）时，无 Q_R/F 前馈则塔板温度与纯度瞬时干扰大，加入 Q_R/F（0.02717 GJ/kmol，TC 重整定 K_C=1.96、τ_I=11.9 min）后干扰显著减小。进料流量 +20% 扰动下 TC 与 CC-TC 两种结构都能稳定操作、温度回设定值；但进料组成扰动（C3/C4 由 0.40/0.60 改 0.50/0.50）暴露纯 TC 的缺陷——温度虽回到 337.4 K，xD 中 iC4 却漂至 3%；CC-TC 则通过组分控制器把 SP 温度调到 335.2 K，维持 xD 杂质 2%，釜液几乎不变。结论：温度控制快但不保纯度，组分控制保纯度但慢，串级兼得。

## 关键要点
1. 稳态转动态的必做清单：设备尺寸（5 min/50% 准则 + 长径比 2）、阀门有效相态、进料板压力对齐、Pressure Checker、Export "Pdriven Dyn Simulation"。
2. 控制器按"先液位/流量（启发式参数），后温度/组分（继电反馈+TL）"顺序搭建，每加一个回路就试运行一段并保存快照。
3. 所有 PV/OP 动作方向必须逐回路确认（液位控馏出/釜液出为正作用，流量、温度、组分控制器为反作用），错误的作用方向会立即发散。
4. 温度回路加 1 min、组分回路加 3 min 死时间是得到真实、可复现整定结果的前提；插入死时间的时机在回路跑通之后。
5. 继电反馈测试默认振幅 5%，5~6 个循环后 Finish；TL 整定（K_U/3.2、2.2P_U）刻意保守，因为精馏塔受液泛/液漏水力学约束。
6. 比值控制的单位陷阱：流量比单位自洽，热量比必须换算成 GJ/kmol；乘数器输出应进入控制器 SP/输出叠加，不能直连阀门。
7. 温度控制守不住产品纯度（进料组成扰动下 xD 漂移 1 个百分点），组分-温度串级是"快 + 保纯度"的标准答案。
