# Luyben 精馏设计与控制 · 速查表

## 决策规则（当X→做Y，因为Z）
- **VLE 先行**：判断体系可否精馏，先画 Txy/xy 图；烃类用 Chao-Seader，非理想用 NRTL/UNIFAC/Wilson；物性选错=垃圾进垃圾出 [ch1]
- **恒 α 才可用** $y=\alpha x/(1+(\alpha-1)x)$ 免迭代；α 随组成/温度变→必须泡点迭代 [ch1]
- **压力不是猜的**：冷源温度+20K温差→回流罐温度→由轻组分蒸气压反推，取最低可行压力；压力↑→α↓→能耗↑ [ch3]
- **Design Spec/Vary 串行不并行**：先 D（收塔顶，影响强）后 RR（收塔底），给足上下限；板数<N_min 时数学无解 [ch3]
- **启发式二选一**：N=2N_min+2 或 RR=1.2RR_min，同时用会冲突；实际最优常是 N≈2.8N_min、RR≈1.04RR_min（启发式偏保守~5%）[ch2/4]
- **TAC 判一切经济问题**：扫板数/压力算 TAC（设备/3年+能耗），曲线平坦、能耗占~80%主导；能源价假设比板数精调重要 [ch4]
- **跨精馏边界**：单塔产品必须在同一剩余曲线区域；跨越靠倾析器（液液分相）或第二塔混合点 [ch1/5]
- **萃取精馏 S/F 与 RR 都取"够用最小"**：回流太小溶剂窜顶、太大稀释溶剂让轻组分上窜 [ch5]
- **循环物流三步闭合**：开环估组成→Design Spec 收敛单塔→逐环撕裂（Convergence→Tear）；强 VLLE 双循环稳态不收敛→转动态闭合 [ch5]
- **共沸组成随压力大幅移动→变压精馏**；否则萃取精馏（产品更纯但能耗高）[ch5]
- **热耦合塔**：低压塔回流罐可用冷却水 + 高低压温差~20K；净操作用流程级 Design Spec（DELTAQ=QR1+QC2≈0）[ch5]
- **控制板五判据按序试**：斜率→灵敏度→SVD→恒定温度→最小产品波动；**冲突时听最小产品波动**（最贴控制目标）[ch6]
- **避开进料板**：温差虽大但是进料扰动驱动，非可反馈信号 [ch6]
- **先 ZSA 再定比值**：哪个比值（RR 或 R/F）对进料组成最不敏感就固定哪个——理想体系固定回流量，非理想体系可能固定回流比 [ch6]
- **双温控可行性看 SVD 条件数 CN**：CN≈3 可行，CN>10（两板太近）基本无望，只控一温度+一组成 [ch6/10]
- **稳态增益后过动态筛**：回流量控塔下部板受水力滞后（3~6s/板）；提馏段温度永远用再沸器热量控 [ch6/8]
- **转动态清单**：5min/50% 持液定径（长径比2）、阀门相态正确、进料阀出口压=进料板压、Pressure Checker、Export "Pdriven Dyn Simulation" [ch7]
- **控制器顺序**：先液位/流量（启发式：液位P Kc=2、流量 Kc=0.5/0.3min），后温度/组分（继电反馈+TL）；温度加1min、组分加3min死时间（回路跑通后再插）[ch7]
- **温度控制守不住纯度**：进料组成扰动下 xD 漂移1个百分点；**组分-温度串级是"快+保纯度"标准答案** [ch7]
- **比值单位陷阱**：热量/进料比必须换 GJ/kmol；乘数器输出接控制器 SP，不直连阀门 [ch7]
- **温度分布陡峭的塔用3板平均温度**，摊平大过程增益 [ch8]
- **冷凝器动态模型**：安全/真实分析必须用 LMTD（冷媒流量操纵）或显式 HeatX，Constant duty 严重失真 [ch8/13]
- **控制结构评比双视角**：单塔纯度保持 vs 送下游流量平稳（CS3 型 Qc控压牺牲单塔换全厂平稳）；双组分控制可兼得 [ch8]
- **反应精馏可行性**：产物挥发度明显轻/重于反应物（αC>αA>αB>αD）才值得做；压力=反应温度与分离温度的折中 [ch9]
- **净操作绝不用固定进料比**：双产物体系用两个温度控制器；单产物（ETBE/TAME）必须加内部组成控制器平衡计量 [ch9]
- **反应板数有最优值**：太多逆反应回升、能耗反增 [ch9]
- **侧线塔第一判据是挥发度**：液相侧线要求最轻/中间 α 大（24可行，1.7不可行）；汽相侧线要求中间/最重 α 大（4.4可行）[ch10]
- **侧线流量必须浮动**：液相侧线配 S/R 比例、汽相侧线配 S/Q_R 比例；固定侧线=馏出纯度崩坏 [ch10]
- **石油塔控制核心回路是"产品流量→自身ASTM馏点"**（Stream Sensor 取 PV）；相邻产品 95%/5% 点不独立（定律1）；中段回流=能耗vs分离精度（定律2）；汽提蒸汽只移初馏点/闪点（定律3）[ch11]
- **降荷控制选型**：循环控制（TC操纵塔进料）> VPC > 双温度控制；任何结构必须保留温度控制（第二定律）[ch15]
- **板压降/塔压明显波动→上压力补偿温度控制 PCTC**（板越靠塔底越敏感）；实现：两压力×两组成点 Txy 拟合 x=(c1P+c2)T+(c3P+c4)，公制单位 [ch16]
- **有超驰（选择器）必有防积分饱和**：ERF=Comparator+Multiply+Multisum+Lag(增益1,τI)+低选器；Lag初始化先fixed后free [ch18]
- **补加量/总量极小的回路不用 PI**（双积分器振荡），纯比例即可 [ch14]

## 决策树：控制方案选择
- 单端 vs 双端：ZSA 后某比值几乎不变→单端；两端都显著变→双端（加分析仪）
- 温控板位置：陡峭分布→3板平均；正常→斜率/SVD 选板；控提馏段→用 QR；高RR塔→QR控液位+D控近顶温度
- 压力会变（负荷/环境/热集成）→ PCTC；不变→普通 TC
- 循环强非线性流程收敛：萃取循环=Wegstein易；变压循环=物料衡算给初值；VLLE双循环=动态法；双循环强非线性=同伦法（临时分流5%→0）[ch5/17]

## 危险信号
- ** Aspen 导出报"压降太小"** → 降堰高（0.05→0.025m），勿改压降 [ch7]
- **运行键红/过约束** → Flowsheet Equations 输入变量 Fixed 改 Free [ch8/13/16/18]
- **Dynamics 初始化失败（带冷凝器塔）** → 拆成仅再沸器塔+外置 HeatX/Flash2 回流罐 [ch14]
- **胺系统压力无规则振荡** → 变步长积分器；改 Gear+固定步长0.0001h [ch8/14]
- **汽相馏出物控压且下游有装置** → D 大而快波动扰下游；改 CS3 或加双组分控制 [ch8]
- **Decanter 模型水相液位正作用** → 3.5h 模拟崩溃；需反作用或换 Flash3 [ch8]
- **稳态收敛≠设计合理** → 板数<N_min 无解；多重稳态（扫参两侧逼近验证分支；MeAc 回流 0.12→0.08→0.09 回不去）[ch3/5/6]
- **小流量回路稳态阀位13~14%** → 扰动即饱和；增大 COmax、泵 EpowerR，或加 Q_R/F 前馈 [ch10/11]
- **单一温度控制的纯 TC 遇组成扰动** → 温度回设定但纯度漂移；上 CC-TC 串级 [ch7]
- **蒸气量被钳位后只靠 R 控温** → 控温板隔34块板，积分时间被迫31min，xD 跌至80%；改循环控制 [ch15]
- **两个 PI + 低选器无防饱和** → 未选中者积分到上限，切回要等~1h，超驰形同虚设；上 ERF [ch18]
- **冷凝器故障比再沸器超量危险**：10~20s vs >1min 到超压；最有效保护=联锁切断再沸蒸汽 [ch13]
- **多稳态/滞回**（共沸体系 ZSA 来回扫描走不同分支）→ 勿当数据噪声 [ch6]
- **补加水失衡** → 数小时内吸收剂浓度漂移、CO2 吸收崩坏 [ch14]
