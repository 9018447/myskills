# Chapter 1: 化工模拟计算概述

## Core Idea
化工过程模型化是设计、分析、优化、控制与生产调度的基础；数学模型以"三传一反"（质量传递、热量传递、动量传递和化学反应）即质量平衡、热量平衡、动量平衡结合反应动力学而建立。由于通用数值算法已相当成熟，编程的正确姿势是把现有通用算法函数"组装"或"集成"到自己的程序中——本书首创省略算法推导、直接调用 MATLAB 内建函数与工具箱函数的编写框架，"拿来就用"。

## Frameworks Introduced
- **"三传一反"建模框架**: 作者原话——"化工过程一般包括'三传一反'，即质量传递、热量传递、动量传递和化学反应，数学模型就是以质量平衡、热量平衡和动量平衡为基础并结合反应动力学而建立的模型方程式"。
  - When to use: 任何化工过程（未建立或已建立）的研究开发、设计、运转评估、控制和改进
  - How: 以三大平衡方程为基础 + 反应动力学关系式，构成模型方程组，再数值求解
- **传统算法书的五步框架 vs 本书省略框架**: 传统论述算法需 ①数学模型 → ②算法数学推导得迭代公式 → ③画程序方框图 → ④详述计算步骤 → ⑤编写调试通用算法函数。作者原话——"本书最大的特色之一，就是尽量使用 MATLAB 内建函数及工具箱函数，实际省略了以上的②~⑤步……首先提出对应问题的数学模型，再简要介绍该模型有哪些解法，然后直接列出 MATLAB 提供的相应求解函数，并介绍该函数的用法"。
  - When to use: 学习/查阅任何数值求解任务时（本书通篇体例）
  - How: 模型 → 解法简介 → MATLAB 函数 → 化工实例（模型建立、程序说明、程序清单、计算结果）
- **自编程必要性判据**: 作者原话——商用软件"主要针对通用性问题，软件包中不包含有对特定情况需要的专用程序模块"；"有时，我们只需要对某个关键过程或设备进行模拟计算，这种情况商用流程模拟软件通常不能解决，只能通过自己建模、编程进行模拟计算"。
  - When to use: 判断"有了 Aspen 还要不要自己编程"
  - How: 流程中特定设备模型需按特定情况建立并作为独立模块供流程软件调用；仅需模拟某个关键过程/设备时商用软件不能解决；科研涉及较新课题多数需自编程
- **最佳编程方案（混合编程）**: 作者原话——"更佳的编程方案是尽量使用 MATLAB 强大的算法函数和工具箱，当某些计算任务不能直接用 MATLAB 内部函数和工具箱函数，或者用 MATLAB 编程计算效率较低时，这部分计算任务可用 CVF 或 VC 实现，然后通过混合语言编程接口加以调用"。
  - When to use: MATLAB 内建函数/工具箱覆盖不了，或循环运算慢成为瓶颈时
  - How: 主程序用 MATLAB，瓶颈部分用 CVF（Compaq Visual Fortran 6.5）或 VC 实现，经混合语言接口调用

## Key Concepts
- **化工过程模型化**: 化工过程设计与分析、过程研究与开发、系统工程、模型预测、优化和控制以及生产计划和调度的基础
- **三传一反**: 质量传递、热量传递、动量传递（三传）和化学反应（一反），化工过程的构成要素
- **数学模型**: 以质量平衡、热量平衡和动量平衡为基础并结合反应动力学而建立的模型方程式；其建立是化工模拟的关键步骤
- **Aspen / Pro II**: 国际知名化工流程模拟软件（分别为麻省理工学院与模拟科学公司产品），用于工厂物料衡算和能量衡算的流程模拟，通用性好但不含特定情况专用模块
- **Fluent**: 著名计算流体力学软件，可解复杂流体力学问题但比较昂贵
- **Numerical Recipes / IMSL**: 成熟通用算法程序集/数学库（含 FORTRAN 与 C/C++ 版本），通用算法源代码的代表性资源
- **MATLAB**: Mathworks 公司 1984 年推出的数值计算软件，含 600 多个常用算法内建函数、多种工具箱（偏微分方程、最优化、数理统计、样条函数、神经网络等）和 simulink 仿真模块，函数源代码公开
- **混合编程**: 用 OOP 高级语言（VC、VB）开发界面、数值计算调用 CVF 附带的 IMSL 动态连接库，或 MATLAB 与 CVF/VC 接口互调
- **130 个实例**: 本书提供的化工应用实例（含程序）数量，覆盖从代数方程到二维动态 PDE、多响应加权非线性参数估计等

## Mental Models
- **Use "组装"通用算法 when 编程做数值计算**：作者原话——"进行数值计算方面的编程时，完全没必要再去编写这些通用算法函数，而直接把现有的通用算法函数'组装'或'集成'到自己的程序中，这样不仅编程效率高，而且计算比较稳定"。
- **Use 自编程 when 商用软件有覆盖缺口**：全流程衡算用 Aspen/Pro II；特定设备模块、关键单过程模拟、中小型企业未购置软件、科研新模型——四种情形都指向自己建模编程。
- **Use MATLAB first, CVF/VC only for 瓶颈**：MATLAB 算法齐全、简单易学、图形可视化与符号运算强大；其不足仅是"循环运算相对较慢"，这部分交给 CVF/VC 加速。
- **模型导向而非算法导向**：硕士生已学过数值分析，本科生应把时间花在"模型建立、用 MATLAB 快速数值求解及结果分析"，而非算法细节与 Fortran/C 繁杂编程。

## Anti-patterns
- **在书中/课程中重述算法推导与手写通用算法函数**: 传统五步框架的②~⑤步在 MATLAB 环境下是冗余——"这种避开算法的细节描述，完全不影响我们的模拟工作"；且 Fortran/C 的内部函数与 Numerical Recipes、IMSL 算法函数"都比较有限，且对编程能力要求较高，编程效率较低"。
- **以为商用化工软件能解决一切模拟需求**: Aspen/Pro II 不含特定情况专用模块，关键过程/单设备模拟、简单流体力学问题（买不起 Fluent）仍需自编程；"即使有各种商用化工软件，仍十分必要掌握通过建模编程进行化工模拟计算的方法和技能"。
- **让 MATLAB 承担循环密集计算而不混合编程**: MATLAB"循环运算相对较慢"，明知瓶颈仍不引入 CVF/VC 是次优方案。

## Worked Example
本章无计算例题（实例从第 2 章开始）。作者完整走通的是一条**选型与编写框架论证链**：
- **问题**: 有了 Aspen 等商用软件，还有没有必要自己编程做化工模拟？
- **推理**: (1) 化工过程模型化是设计/分析/优化/控制的基础 → 模拟能力是基本功；(2) 模型来自三传一反的三大平衡+反应动力学 → 模型必须按特定情况自己建；(3) Aspen/Pro II 只做通用流程衡算，特定设备模块要用户自建供其调用，关键单过程模拟只能自编程，中小企业多未购置软件，科研新模型更需自编程；(4) 算法已成熟（Numerical Recipes、IMSL、MATLAB 内建函数）→ 不写通用算法，直接组装；(5) 语言选 MATLAB（算法齐全+简单易学+图形+符号运算+源代码公开），循环慢的部分用 CVF/VC 混合编程。
- **结论**: "十分必要掌握通过建模编程进行化工模拟计算的方法和技能"；基于 MATLAB 的数值模拟计算"已经成为国内外的一种趋势"。

## Key Takeaways
1. 化工数学模型 = 质量平衡 + 热量平衡 + 动量平衡 + 反应动力学（"三传一反"）；这是所有后续章节建模的统一出发点。
2. 通用算法函数一律"拿来就用"（MATLAB 内建函数/工具箱、Numerical Recipes、IMSL），自编算法既低效又不稳定。
3. 自编程的适用判据：特定设备的专用模块、关键过程/单设备的单独模拟、未购置商用软件、科研新模型。
4. MATLAB 的核心优势：600 多个内建函数、丰富工具箱、源代码公开、图形可视化与符号运算兼备、支持混合编程；唯一短板是循环运算慢。
5. 最佳编程方案：MATLAB 为主，不能覆盖或效率低的计算任务用 CVF/VC 实现，经混合语言接口调用。
6. 本书体例 = 模型 → 解法 → MATLAB 函数 → 化工实例（含程序清单与计算结果），130 个实例兼作化工应用程序集。
