# Chapter 8: 化工试验设计及数据处理

## Core Idea
实验设计是"以概率论、数理统计以及最优化方法等为理论基础，进行科学合理的实验安排"：先用正交表以最少试验次数均衡覆盖多因素空间，再用极差分析（直观分析法）或方差分析把因素效应与试验误差分离开；对非线性机理模型的参数精估，则用最小容积/D-最优等序贯设计主动选点，而非被动尝试。

## Frameworks Introduced
- **正交试验法**: "用正交表安排试验方案，它可以解决多因素、多水平及多指标这一类的试验问题"
  - When to use: 多因素多水平寻找最佳操作条件或最佳配方、估计模型参数
  - How: ①制定因素-水平表 → ②选正交表（原则：r 等于因素水平数，m ≥ 因素个数，n 尽可能小）→ ③表头设计（无交互作用时因素可任意安放；有交互作用必须查交互作用表预留交互列）→ ④按行做 n 次试验 → ⑤极差分析或方差分析
- **极差分析（直观分析法）**: 逐列计算 K（同水平指标之和）、k（平均值）、R（极差，"k 的第 j 列中最大值与最小值之差"）
  - When to use: 计算量小、快速找优与排主次；但"不能估计试验误差的大小，很难断定哪个因素影响显著"
  - How: 每个因素选 k 最大的水平为最优水平；按 R 大小排主次（"极差大，对试验指标影响大，为主要因素"）
- **方差分析**: "将因素水平（或交互作用）的变化所引起的试验结果间的差异与误差的波动所引起的试验结果间的差异区分开来的一种数学方法"
  - How: $P=\frac{1}{n}(\sum Y_i)^2$，$Q_j=\frac{1}{r}\sum_i K_{ij}^2$，$S_j=Q_j-P$；$f_T=n-1$，$f_j=s-1$，$f_E=f_T-\sum f_j$；$F_j=\bar{S}_j/\bar{S}_E$，若 $F_j>F_{1-\alpha}(f_j,f_E)$ 则因素 j 显著
- **最小容积设计（Box-Lucas 准则）**: "选择操作变量的格点，使 $(X'X)^{-1}$ 的行列式极小，或使 $X'X$ 的行列式极大"——置信域容积极小
  - When to use: 精确估计（非线性）机理模型中的全部参数；优点是"所得置信域小，而且减少了被估参数之间的相关性，并可量度实验误差"
  - How: 模型在当前参数估值 $\hat\beta$ 处一阶泰勒展开，$V(\hat{\boldsymbol\beta})=(\boldsymbol{X}'\boldsymbol{X})^{-1}\sigma^2$；序贯迭代"设计-实验-参数估计"直至参数精度基本不能再提高
- **球形设计准则**: "使 $X'X$ 中最小的特征根为极大"，"使置信区域的形状尽可能的圆"；两者关系 $\det X'X=\prod_{i=1}^p\lambda_i$
- **D-优化设计（D-Optimal Designs）**: "使 Fisher 信息矩阵 $X^TX$ 的行列式最大化……等价于使参数协方差矩阵的行列式最小化"，即"使线性模型参数 β 的回归估计的置信椭球的体积最小化"
  - How: `cordexch()`（坐标交换算法，增量为设计矩阵单个元素）或 `rowexch()`（行交换算法，增量为行元素）；model 参数：`'linear'/'l'`（默认，常数+线性项）、`'interaction'/'i'`、`'quadratic'/'q'`（交互+平方项）、`'purequadratic'/'p'`
- **序贯实验设计**: "最优化方法与统计理论在实验规划中的应用"，包括最佳序贯判别和最佳序贯估计；优点是"可以利用前面的实验中得到的信息来设计随后的实验"
  - How: ①预实验覆盖实验域大部分 → ②非线性最小二乘得参数初值 → ③按最小容积/形状准则用 Marquardt 法设计下次实验 → ④做实验 → ⑤新旧数据一起重新估参 → ⑥重复②~④

## Key Concepts
- **试验指标**: "试验需要考虑的结果"，如转化率、收率、产品性能、成本、利润
- **试验因素**: "对试验指标有影响的变量，用大写字母 A、B、C…表示"
- **因素的水平**: "每个因素可能处在的状态"
- **正交表**: $n\times k$ 矩阵，各列由 1..m 构成且"任意两列搭配均衡"，记为 $L_n(m_1\times m_2\times\cdots\times m_k)$；两个特性：每列不同数字出现次数相等；任意两列的有序数对各出现次数相等
- **交互作用**: 以 A×B 表示；二水平交互作用占 1 列，三水平交互作用占 2 列
- **正交表自由度**: "f表 = 行数 − 1"（选表判据：f表 ≥ Σf因，其中 f因 = 水平数−1，交互作用 f因 = (s−1)²）
- **F 比**: $F=\frac{S_{因}/f_{因}}{S_{误}/f_{误}}$，用 F 分布表临界值 $F_{1-\alpha}(f_j,f_E)$ 判断显著性
- **偏差平方和 S**: "一组数中各个数与它们的算术平均值之差的平方和"，反映数据分散程度；自由度为 n−1
- **导数矩阵 X**: $x_{iu}=\partial f(\boldsymbol\beta,\boldsymbol\xi_u)/\partial k_i$，n×p 阶；模型对参数非线性时 X 是待估参数的函数
- **二元表/二元图**: 有交互作用的因素选取水平时必须画的水平组合-指标对照表，"进行比较后再选择对指标较优的水平"

## Mental Models
- **Use 正交表 when 全面试验不可行**: 三因素三水平全面试验需 $3^3=27$ 次，$L_9(3^4)$ 只需 9 次；选表判据一句话——r 对水平数、m ≥ 因素数、n 尽量小。
- **Use 方差分析 when 极差分析不够**: 极差分析给不出误差量级；要判断"显著/不显著"必须做方差分析，且要给误差（空白列）留列。
- **Use 二元表 when 因素有交互作用**: "有交互作用的因素，其水平的选取不能单独考虑"，必须画二元表比较水平组合（还可结合提高工效选时间短的组合）。
- **Use D-最优设计 when 模型参数需精估**: 试验次数 ≥ 模型待估参数个数（如 6 参数二次模型最低 6 次，取 8 次更准）；先 cordexch 生成 settings，再映射到真实实验条件。

## Anti-patterns
- **简单比较法（每次只改一个因素、固定其他）**: "选点代表性很差，同样的试验次数，提供的信息不够丰富；无法考察因素间的交互作用"
- **凭尝试法找最优条件**: 例8-8 中尝试法做 13 次实验，"除非运气特别好以外很难找到"使反应速率最大的设置；D-最优设计 13 次每次都能找到 (p1=100, p2=300, p3=10)
- **把不显著因素写进最优条件**: 例8-4 中 B、D 均不显著，最优条件应写 A₃BC₂DE₁（B、D 水平任意，按实际选易实现的水平），而非表面上的 A₃B₂C₂D₂E₁
- **有交互作用却不查交互作用表**: 交互作用列被主效应占用会导致效应混杂；例8-2 中 A×B 必须占第 3 列
- **交互作用不作归并检验**: S_AB、S_AE 小于空白列平方和 Sempty 时应并入误差（例8-4：Se = 0.064+0.046+0.046 = 0.16），否则误差自由度被低估、显著性误判

## Code Examples

```matlab
function OrthExpAnalysis1 % 正交试验的极差分析
NL = 3; NF = 3; r = 3; % NL: 水平数, NF: 因素数, 每个水平有 r 次试验
DATA = ... % DATA 矩阵的前三列是正交试验方案, 第四列为试验指标--收率
[1 1 1 31;
1 2 2 54;
1 3 3 38;
2 1 2 53;
2 2 3 49;
2 3 1 42;
3 1 3 57;
3 2 1 62;
3 3 2 64];
A = DATA(:, 1:NF); Y = DATA(:, NF+1);
for i=1:NL % i:水平
    for j=1:NF % j:因素（列号）
    K(i, j) = sum(Y(find(A(:, j)==i)))
    end
end
k = K/r, R = max(k(:, :)) - min(k(:, :)) % R: 极差
```
- **What it demonstrates**: 极差分析全部计算只需双重循环按列求同水平指标和 K，除以 r 得 k，再取各列极差 R——主次顺序与最优水平一目了然。

```matlab
xa = sum(Y)/length(Y),    xT = sum(Y),    P = 1/(NL*r)*xT^2
j=1:NF;    Q(j) = sum(K(:, j).^2)/r,    S = Q - P    % S: 各因素的平方和
ST = sum(S),    Sav = S/(NL-1)    % ST: 总平方和, Sav: 各因素的均方
F = Sav(1:NF-1)/Sav(end)    % F: 显著性检验
```
- **What it demonstrates**: 正交试验方差分析的核心五行：由 P、Q、S、均方到 F 比的全部计算（程序 OrthExpAnalysis3.m）。

```matlab
settings = cordexch(3, 13, 'q'); % settings: 因子设置矩阵
mr = p(2, :); mr = mr(ones(13, 1), :); % mr: middle row, i.e., middle level
hr = (p(1, :) - p(3, :))/2; hr = hr(ones(13, 1), :);
expCond = settings.*hr + mr; % expCond: settings 的相应实验条件
% 数据分析: 由非线性模型 Nonlinear Model 估计参数
[beta, resid, j] = nlinfit(x, y, @hougen, beta0)
ci = nlparci(beta, resid, j)
```
- **What it demonstrates**: D-最优设计→实验条件映射→nlinfit 非线性回归→nlparci 置信区间的完整 DOE-建模流水线（程序 DOE.m，Hougen-Watson 动力学参数估计）。

## Reference Tables

| 设计方法 | 试验次数 | 能否考察交互作用 | 类型/特点 |
|---|---|---|---|
| 全面试验法（完全析因设计） | 因素水平数全组合（3³=27） | 能 | 析因（先验型）；全面但太费时 |
| 简单比较法 | 少 | **不能** | 选点代表性差，信息不丰富 |
| 正交试验法 | 正交表行数（如 L₉=9、L₈=8、L₂₇=27） | 能（查交互作用表留列） | 析因（先验型）；搭配均衡 |
| 序贯试验法 | 迭代增加 | 利用前面信息设计后续 | 最优化+统计理论；主动选点 |

| MATLAB 函数 | 设计类型 | 备注 |
|---|---|---|
| `fullfact(levels)` / `ff2n(n)` | 完全析因设计 | ff2n(3) 等效于 fullfact([2 2 2]) |
| `fracfact(gen)` | 不完全析因设计 | gen 为生成器字符串，返回混杂模式 conf |
| `bbdesign()` / `ccdesign()` | 响应面设计 | Box-Behnken / 中心复合设计 |

## Worked Example
**例8-1（无交互作用的正交实验极差分析）**：求化工产品收率 Y 最优条件。因素-水平：温度 T(80/85/90℃)、压力 p(150/200/250 kPa)、催化剂 C(C₁/C₂/C₃)。
- **方法**: 三因素三水平 → 选 L₉(3⁴)；三因素任意放三列表头，留 1 空白列；按 9 行做 9 次试验（收率 31%~64%）。
- **MATLAB 要点**: `OrthExpAnalysis1.m` 以 DATA 矩阵（前 3 列方案+第 4 列指标）为输入，双重循环 `K(i,j)=sum(Y(find(A(:,j)==i)))`，`k=K/r`，`R=max(k)-min(k)`。
- **结果**: k 矩阵显示 T 列第 3 水平(61)、p 列第 2 水平(55)、C 列第 2 水平(57)最优 → 最优生产条件 T₃P₂C₂（90℃、200 kPa、2号催化剂）；极差 R=[20 8 12] → 主次顺序 T→C→P。此组合未在 9 次试验中出现过，验证试验收率 74%，高于正交试验中最好的第 9 号（64%）。作者指出："当因素没有交互作用时，用此法选出的试验条件就是全面试验中最好的。"

## Key Takeaways
1. 选正交表的判据：r 等于因素水平数、m ≥ 因素个数、n 尽可能小；有交互作用时先算自由度——f表(=行数−1) 必须 ≥ Σf因（因素 f=水平数−1，交互作用 f=(s−1)²，即三水平交互占 2 列）。
2. 无交互作用时，各因素取 k 最大的水平组合就是最优条件；若该组合未在正交表出现过，必须做验证试验。
3. 要判断因素是否"显著"，极差分析不够，必须做方差分析并给误差留空白列；显著性判据 $F_j>F_{1-\alpha}(f_j,f_E)$。
4. 交互作用的平方和若小于空白列平方和，就并入误差不再考虑——省自由度、提检验力。
5. D-最优设计的试验次数必须 ≥ 模型待估参数个数；cordexch 每次运行 settings 不同，但都能定位最优实验点。
6. 化工数据处理全景索引（作者 8.6 节）：插值/平滑/拟合→第3章，参数估计→第7章，极差/方差分析→本章，神经网络函数逼近→第9章。
