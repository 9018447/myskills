# 第1章: 汽-液相平衡(VLE)基础

## 核心思想
精馏的物理依据是汽-液相平衡（VLE）：只有当平衡时汽、液两相组成不同，才可能实现组分分离。对 VLE 的定量理解（蒸气压→相图→相对挥发度→泡点→非理想性/共沸→精馏边界）是精馏塔分析、设计和控制的全部基础。

## 关键框架与原理
- **蒸气压曲线 ($\ln p^S$ vs $1/T$)**: 表征纯组分挥发性。苯/甲苯曲线大致平行 ⇒ 分离难易度几乎不随塔操作压力变化；其他物系（曲线不平行）则压力影响显著。蒸气压只与温度有关。
- **二元相图 (Txy 图 / xy 图)**: 恒压下分析二元精馏的工具。Txy 图上给定温度画横线读出互成平衡的 $x$、$y$；两曲线间为两相区，上方过热汽，下方过冷液。xy 图上曲线离对角线越远越易分离（对比：苯/甲苯易分离，丙烯/丙烷因沸点接近而极难）。
- **物性方法选择**: 烃类体系常用 Chao-Seader；常用方法还有 van Laar、Wilson、Unifac、NRTL。选择依据：文献 VLE 数据（DECHEMA 手册）、实验室/中试/装置数据（注意装置数据与板效率纠缠，不能单独回归 VLE）。
- **相对挥发度 $\alpha_{LH}$**: 把 VLE 数据浓缩为一个数的框架。恒定 $\alpha$ 时可直接由液相组成算汽相组成（见公式），无需迭代；$\alpha$ 随组成/温度变化时不可用恒 $\alpha$ 近似，必须做泡点迭代。
- **泡点计算**: 已知 $p$ 和 $x_j$，迭代求 $T$ 使 $\sum x_j p^S_j(T) = p$，同时得 $y_j = x_j p^S_j / p$（理想体系）。蒸气压函数有解析导数，适合 Newton-Raphson 迭代。
- **三元相图与杠杆规则**: 指定 $x_1, x_2$ 即定组成；两股物流混合点必在两组成点连线上（共线性），用于精馏塔即 $F$、$x_D$、$x_B$ 三点共线，且 $D/B = (z_1-x_{B1})/(x_{D1}-z_1)$ 方向的线段比。第2、5章推断精馏结果的核心几何工具。
- **剩余曲线分析**: 容器中不断移出汽相时液相组成的轨迹 $\mathrm{d}x_j/\mathrm{d}\theta = x_j - y_j$；与全回流塔内组成剖面方程 $\mathrm{d}x_j/\mathrm{d}h = x_{nj} - y_{nj}$ 相同。剩余曲线从最轻组分出发、终于最重组分。可行性判据：(1) $x_D$ 与 $x_B$ 必须位于同一条剩余曲线附近；(2) 两点连线必须通过进料点 $z$。
- **精馏边界 (Distillation Boundary)**: 共沸物把组成空间切成多个分离区域，进料落在哪个区域就只能得到该区域的产品。二元最低共沸体系：进料小于共沸组成→塔顶近共沸物、塔釜重组分；大于则反之。三元中连接两个二元共沸点的直线即边界。

## 关键概念
- **蒸气压 $p^S$**: 特定温度下纯组分汽-液共存时的压力，纯组分属性，随温度指数增长。
- **轻/重组分**: 按挥发度（非密度）划分；轻组分蒸气压高、沸点低，平衡汽相中富集。
- **Txy 图**: 恒压下温度对液相（饱和液线）与汽相（饱和汽线）组成的关系图。
- **相对挥发度 $\alpha_{LH}$**: 两组分的 $(y/x)$ 之比，$\alpha$ 越大分离越容易。
- **泡点**: 已知组成和压力时液相开始沸腾的温度，由 $\sum x_j p^S_j = p$ 迭代确定。
- **活度系数 $\gamma_j$**: 液相非理想性校正因子；只有组分分子极为相似（如苯/甲苯）时才 $\approx 1$。
- **逸度系数 $\sigma_j$**: 汽相非理想性校正因子；中低压下通常 $\approx 1$。
- **共沸物**: 汽、液相组成相等的点，$xy$ 曲线在此穿越 45° 线；板间组成不再变化，构成精馏边界。分均相/非均相、最低/最高共沸。
- **剩余曲线**: 固定压力下连续移走汽相时残液组成在三元图上的轨迹，模拟全回流精馏剖面。

## Aspen 操作要点
1. **生成 Txy 图**: 菜单栏 Tools → Analysis → Property → Binary，弹出对话框中指定曲线类型（Txy）、压力（如 1 atm）与物性方法（如 Chao-Seader），点 **Go**。改压力可得多组曲线（压力越高温度越高）。
2. **生成 xy 图与活度系数图**: Go 后自动打开 Binary Analysis Results 窗口（内含数据表）→ 底部 **Plot Wizard** → 选 **"YX"** 图型 → Next → Finish。同一 Plot Wizard 中选 **Gamma** 选项可画活度系数-组成曲线。
3. **共沸搜索**: Tools → Conceptual Design → **Azeotropic Search**，在窗口中指定组分、组成和压力，点 **Azeotropes** 查看结果（乙醇/水：351 K 均相共沸，乙醇 89.3 mol%）。
4. **非均相体系 VLE**: 做 Txy 分析时在 Property Model 下把 **Phases 选为 "Vap-Liq-Liq"**（水/正丁醇体系必须如此才能显示双液相）。
5. **剩余曲线图**: Tools → Conceptual Design → **Ternary Maps**，选 3 个组分及压力 → 点 **Ternary Plot** → 在图上右击选 **Add → Curve**，光标变十字线后点击某点即加一条过该点的剩余曲线；或用右侧菜单第三个选项批量定点、右键生成多条曲线。

## 公式与方程
- 两参数蒸气压方程（常数取决于压力/温度单位）:
$$\ln p_j^S = C_j + D_j/T$$
- 相对挥发度定义（二元及多元）:
$$\alpha_{LH} = \frac{y_L/x_L}{y_H/x_H}, \qquad \alpha_j = \frac{y_j/x_j}{y_H/x_H}$$
- 恒 $\alpha$ 时汽-液组成关系:
$$y = \frac{\alpha x}{1+(\alpha-1)x}, \qquad y_j = \frac{\alpha_j x_j}{\sum_{j=1}^{NC} \alpha_j x_j}$$
- 相平衡普遍式（化学势相等）:
$$\mu_j^L = \mu_j^V \;\Rightarrow\; y_j p\,\sigma_j = x_j p_j^S \gamma_j$$
- 泡点方程（理想体系，$\gamma_j=\sigma_j=1$）:
$$p = \sum_{j=1}^{NC} x_j\, p_j^S(T)$$
- 杠杆规则/共线性（由总物料与组分平衡导出）:
$$F=D+B,\quad F z_j = D x_{Dj} + B x_{Bj},\quad \frac{D}{B} = \frac{z_1 - x_{B1}}{x_{D1} - z_1} = \frac{z_2 - x_{B2}}{x_{D2} - z_2}$$
- 剩余曲线方程及其与全回流塔剖面的等价性:
$$\frac{\mathrm{d}x_j}{\mathrm{d}\theta} = x_j - y_j \;\;\Longleftrightarrow\;\; \frac{\mathrm{d}x_j}{\mathrm{d}h} \approx x_{n+1,j} - y_{nj}$$
（全回流时 $D=0$、$L_{n+1}=V_n$，故 $x_{n+1,j}=y_{nj}$。）

## 反模式
- **随手假定理想液体**: 液相理想（$\gamma=1$）远比汽相理想罕见；分子间有吸引/排斥，组分不相似时（甲醇/水、乙醇/水）活度系数可达 2~7，恒 $\alpha$ 方程和 Raoult 型泡点计算全部失效。
- **$\alpha$ 不是常数仍用 $y_j = \alpha_j x_j / \sum \alpha_j x_j$**: 该式仅在恒 $\alpha$ 假设成立时可用，否则必须做泡点迭代。
- **用工业塔操作数据单独回归 VLE 参数**: 板效率未知且与 VLE 参数耦合，两者不能脱离；应优先用文献/DECHEMA 数据或独立实验室数据。
- **忽视共沸物就直接设计分离流程**: 进料在精馏边界哪一侧决定能得到什么产品；乙醇/水普通精馏最多得到共沸组成（89.3 mol%）。
- **对可能分层体系只做 Vap-Liq 分析**: 水/正丁醇这类体系必须选 Vap-Liq-Liq 相态，否则漏掉非均相共沸与液-液分区。

## 实例演练
全书第一个走通的例子是**乙醇/水体系非理想性分析**（1 atm，Unifac/NRTL 物性方法）：由 Tools→Binary 生成 Txy 图与活度系数表——纯水端 $\gamma_{EtOH}=6.75$（远大于苯/甲苯的近 1），$xy$ 图在乙醇约 90 mol% 处穿越对角线，判明存在均相最低共沸物；再用 Azeotropic Search 精确算出共沸点 351.0 K（78°C，低于乙醇沸点 351.5 K），共沸组成乙醇 89.3 mol%。配套对照体系：甲醇/水（弱非理想，$\gamma$ 范围 2.3~1.66，无共沸）与水/正丁醇（强非理想，Vap-Liq-Liq 相态；1 atm 共沸汽相含水 75.17%，与之平衡的两个液相分别含水 43.86% 和 98.05%）。三个体系梯度化地展示了"分子差异性 → 活度系数 → 共沸 → 非均相分层"的递进逻辑。

## 关键要点
1. 分离之所以可能，只因为平衡时 $y \neq x$；判断一个体系能否精馏，第一步永远是看它的 Txy/xy 图。
2. $\alpha$ 大于 1 的程度直接量化分离难度：苯/甲苯易、丙烯/丙烷难；蒸气压曲线平行的体系，分离能耗对操作压力不敏感。
3. 烃类用 Chao-Seader，强非理想体系用 NRTL/Unifac/Wilson/van Laar；物性方法选错，后续一切设计都是垃圾进垃圾出。
4. 恒 $\alpha$ 时用 $y_j = \alpha_j x_j/\sum \alpha_j x_j$ 免迭代；否则老老实实做泡点 Newton-Raphson 迭代。
5. 剩余曲线 = 全回流精馏剖面的数学镜像；$x_D$、$x_B$、$z$ 三点共线且落在同一剩余曲线带内，分离才可行。
6. 共沸点即精馏边界，把组成图切成独立分离区域——进料落点决定产品，普通精馏无法跨越。
7. 这两个 Aspen 菜单要肌肉记忆：Tools→Analysis→Property→Binary（相图）和 Tools→Conceptual Design（共沸搜索、Ternary Maps/剩余曲线）。
