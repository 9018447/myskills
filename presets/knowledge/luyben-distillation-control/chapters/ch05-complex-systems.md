# 第5章: 复杂体系的精馏模拟

## 核心思想
把第3-4章的理想二元单塔模拟拓展到多组分强非理想体系和复杂塔结构（共沸物、萃取剂、倾析器、双塔、循环物流），核心工具是三元相图/残留曲线认知 + 撕裂流（tear stream）收敛策略；同时预示"同步设计"理念——稳态设计必须为后续动态控制留好结构。

## 关键框架与原理
- **萃取精馏（两塔+溶剂循环）**: 用于形成最小共沸物的二元系（丙酮/甲醇+DMSO）。溶剂从萃取塔顶加入，改变相对挥发度，使一个关键组分随溶剂走塔底；塔底进溶剂回收塔，溶剂循环回用。新增关键自由度：**溶剂/进料比 S/F** 与回流比——两者都不是越大越好：回流太小溶剂窜顶污染馏出物，回流太大稀释塔内 DMSO 浓度让甲醇上窜。
- **三元相图 + 精馏边界（distillation boundary）**: 复杂体系设计的认知地图。残留曲线从共沸点流向重组分顶点；边界线把组成空间分成若干区域，**单塔的塔顶、塔底产品必须落在同一区域内**。要跨边界必须借助倾析器（液液分相）或第二塔的混合点。
- **非均相共沸精馏（乙醇脱水/苯夹带剂）**: 苯作轻夹带剂优先带水上顶；馏出蒸气冷凝后分层，回流罐兼作倾析器——有机相回流、水相去第二塔脱水、塔顶馏出物循环。用双循环跨越精馏边界。
- **变压共沸精馏（pressure-swing）**: 若共沸组成随压力显著移动（丙酮/甲醇从 1 atm 的 77.6% 移到 10 atm 的 37.5%），可用高/低压两塔分离，不引入第三组分、不污染产品。馏出物组成取在各自共沸组成"外侧一点"，是经济优化的决策变量（越接近共沸物→板数↑投资↑，但循环流量↓能耗↓）。
- **多效/热耦合双塔精馏**: 高压塔冷凝器作低压塔再沸器。选压原则：低压塔回流罐温度够低能用冷却水（326 K），高压塔回流罐温度 = 低压塔釜温 + ΔT 驱动力（约 20 K）。用 Flowsheeting Options 的 Design Spec 自动调进料分配比实现"净操作"（QR1 = QC2）。
- **撕裂流收敛策略**: 断开循环物流、给组成/流量的合理初值，逐环闭合。先用开环 "CALC" 物流算出真实循环组成，再闭合并声明 tear stream。收敛难度分级：溶剂循环（Wegstein 两次迭代收敛）＜变压循环（物料衡算给初值，容易）＜非均相 VLLE 双循环（有机回流环稳态法不收敛，需动态法，见第8章）。

## 关键概念
- **最小共沸物**: 沸点低于两纯组分的共沸物（丙酮/甲醇 328 K < 329 K），馏出物组成被锁死在共沸组成附近。
- **萃取剂（溶剂）**: 高沸点第三组分（DMSO，bp 465 K），通过改变液相非理想性移动相对挥发度，不挥发、随塔底走并循环。
- **精馏边界线**: 三元相图中连接各共沸点的线，把组成空间分成单塔无法跨越的区域。
- **非均相共沸物**: 冷凝后形成两个液相的共沸物（乙醇/水/苯三元共沸 337.17 K，为全体系最低沸点），是倾析器工作的热力学基础。
- **撕裂流（tear stream）**: 在流程中人为断开的循环物流，由收敛器（如 Wegstein）迭代使其两端匹配。
- **多重稳态解（multiple steady states）**: 强非理想 VLLE 塔中，同一组输入（回流量、进料、循环流）可收敛到组成截然不同的两个稳态。
- **净操作（net operation）**: 热耦合系统中高压塔冷凝器放热恰好等于低压塔再沸器吸热，无外部公用工程换热器。
- **TAC（年总成本）**: 设备投资折旧 + 年能耗费，用于在馏出物组成、板数、热耦合/单塔方案间做经济权衡。

## Aspen 操作要点
1. **非理想塔收敛**: 塔模块 Convergence 页将 "Standard" 切换为 **"Azeotropic" 或 "Strongly non-ideal liquid"**；默认最大迭代 25 次不够时在 Convergence 项中调大。
2. **萃取精馏流程搭建**: 萃取塔中部进新鲜料、顶部进溶剂；塔底进回收塔；用 Design Spec/Vary（调馏出量与回流比）满足塔顶/塔釜规格；S/F 由参数扫描（sensitivity）确定。
3. **撕裂流设定（溶剂循环）**: 删除循环段 "CALC" 物流，把 SOLVENT 重新接到混合器 M1；进 Data Browser → **Convergence → Tear**，下拉选定 SOLVENT，用默认 Wegstein。
4. **汽提塔（无冷凝器）**: RadFrac 图标组中选 **"Stripper"**；顶部塔板即第 1 块，有机回流从顶板进。
5. **换热器 HX**: Input 页指定出口温度 313 K；压降 0.1 atm —— 压力栏**输入负值表示压降**。
6. **倾析器**: 底部 Separator 标签页选 **Decanter** 图标；Input 设压力 1 atm、热负荷 0（绝热）；在 "Key components to identify 2nd liquid phase" 中把**苯**移入右侧 Key components 框。
7. **逐环闭合（乙醇脱水流程）**: 先开环迭代猜循环组成（C1 馏出蒸气≈02 号三元共沸组成 53.06/27.49/19.45%，313 K 倾析分相得两相组成作初值）→ Design Spec 收敛两塔 → 删 D2CALC、把 RECYCLE 接到阀 V2、设 RECYCLE 为 tear → 闭有机回流环（此环稳态不收敛）。
8. **全流程级 Design Spec（热耦合净操作）**: **Data Browser → Flowsheeting Options → Design Spec → New/OK**；Define 页定义 QR1、QC2（Edit 给定义）；Spec 页设 DELTAQ 目标值与容差；Vary 页选 T1 → Flow/Frac，**ID1 = 2**（分离器 2 号出口流）；**Fortran 页写 DELTAQ**——注意 Aspen 符号约定：吸热为正、放热为负，故目标为 QR1 + QC2 ≈ 0。

## 公式与方程
变压共沸双塔物料衡算（z 为进料组成，进低压塔）：

$$F = B_1 + B_2, \qquad zF = B_1 x_{B1} + B_2 x_{B2}$$

$$B_2 = \frac{F(z - x_{B1})}{x_{B2} - x_{B1}}, \qquad B_1 = F - B_2$$

低压塔衡算（含高压塔馏出物 D2 循环）：

$$F + D_2 = B_1 + D_1, \qquad zF + D_2 x_{D2} = B_1 x_{B1} + D_1 x_{D1}$$

$$D_1 = \frac{F(z - x_{D2}) + B_1(x_{D2} - x_{B1})}{x_{D1} - x_{D2}}, \qquad D_2 = B_1 + D_1 - F$$

动态模拟中冷凝器/再沸器的传热速率（面积固定、温差漂移）：

$$Q = UA\,(T_{D1} - T_{B2})$$

其中 $T_{D1}$ 为高压塔回流罐温度、$T_{B2}$ 为低压塔塔釜温度——稳态下强令 $Q_{R1}=Q_{C2}$ 只满足第一定律，动态下必须按上式满足第二定律。

## 反模式
- **盲目加大溶剂或回流**: 回流过小溶剂窜入塔顶、过大稀释塔内溶剂浓度，两头都毁产品纯度；S/F 必须按"满足纯度下的最小值"选。
- **对强非理想塔用默认 Standard 收敛且不改迭代上限**: 共沸/强非液相体系常不收敛，属算法选错而非模型错。
- **一次闭合全部循环**: 循环初值没验证就闭环，直接跑飞；正确做法是开环算组成→逐环撕裂收敛。
- **在强 VLLE 体系里把一次收敛结果当作唯一答案**: 回流量从 0.12 降到 0.08 再加回 0.09 也回不到原稳态（多重稳态），必须确认收敛到"含水低"的那个目标分支。
- **热耦合设计只用热负荷近似相等就收工**: 17.91 与 18.62 MW "很接近"但不是净操作，必须用流程级 Design Spec 精确匹配。
- **忽视蒸气品位差**: 热耦合省了能耗量却要用更高压蒸气（17 atm vs 6.8 atm），单位价格更高，比较方案必须用 TAC 而非裸能耗。

## 实例演练
- **丙酮/甲醇+DMSO 萃取精馏**: 共沸 328 K、77.6% 丙酮；进料 540 kmol/h（50/50），两塔常压，UNIQUAC；溶剂 750 kmol/h（S/F = 1.39，>500 kmol/h 即可得高纯丙酮），产品均 99.95%；回收塔 17 块板、RR = 0.5；DMSO 损失≈0.00275 kmol/h 作补充溶剂初值，撕裂收敛仅 2 次迭代。萃取塔温度分布极不规则——预示后续控制结构设计的难点。
- **乙醇/水/苯非均相共沸**: 均相二元共沸 351 K（90% 乙醇）；02 号三元非均相共沸 337.17 K（B/E/W = 53.06/27.49/19.45%）。Feed 0.06 kmol/s（84% 乙醇），C1 为 Stripper 31 板（循环进 10 板、进料 15 板、2 atm），C2 22 板（1 atm）；B1 = 0.0504、B2 = 0.0096 kmol/s。回流量扫描暴露多重稳态（0.08 kmol/s 塔底水 43.6% vs 目标分支苯 0.50%）；目标稳态塔底 99.27% 乙醇。Design Spec：C1 塔底苯 0.5%（Vary REFLUX），C2 塔底乙醇 0.1%（Vary B2，RR 可从 2 降到 0.2）。RECYCLE 环可闭合，REFLUX 环稳态法不收敛（第8章用动态法解决）。
- **丙酮/甲醇变压精馏**: 1 atm 共沸 77.6% → 10 atm 37.5%；低压塔 xB1 = 0.005、xD1 = 0.74；高压塔 xB2 = 0.994、xD2 = 0.40。低压塔釜 345 K / 14.77 MW，高压塔冷凝器 407 K / 5.86 MW，ΔT = 62 K。经济性劣于萃取精馏（更大塔径、更多能耗），但产品无溶剂污染。
- **甲醇/水热耦合双塔**: 进料 1 kmol/s（6:4）均分，各塔 32 板、99.9% ×4。C1 0.6 atm（回流罐 326 K、釜 367 K、板压降 0.0068 atm，进料板 19）；C2 5 atm（回流罐 387 K = 367+20，釜 428 K，进料板 18）。流程级 Design Spec 调分配比至 0.5086/0.4914 kmol/s，热负荷匹配 18.10 MW。对比单塔：能耗 35.58→21.81 MW，能耗费 26.4→16.1 万美元/年，TAC 3.77→2.58 百万美元/年，塔径 4.93 m→3.48+2.55 m——虽多一个换热器，总设备费反而更低。

## 关键要点
1. 复杂体系设计先画三元相图：找共沸点、残留曲线方向、精馏边界，判断哪些分离单塔做不到、需要什么"混合点"跨越边界。
2. 萃取精馏的两个设计旋钮是 S/F 和回流比，都在"够用最小"处取值，用参数图（图 5.8/5.9）定。
3. 循环物流一律走"开环估算 → Design Spec 收敛单塔 → 逐环撕裂闭合"三步，撕裂流用 Data Browser → Convergence → Tear 指定。
4. 非理想体系收敛：换 Azeotropic/Strongly non-ideal liquid 算法、加大迭代上限；强 VLLE 塔警惕多重稳态，扫参时从两侧逼近验证分支。
5. 变压精馏的可行性判据是共沸组成随压力大幅移动；馏出物组成（与共沸物的距离）是 TAC 优化的决策变量。
6. 热耦合双塔的选压逻辑：低压塔回流罐可用冷却水 + 高低压温差驱动力约 20 K；净操作用 Flowsheeting Options 的 Design Spec（Fortran 页定义 DELTAQ = QR1 + QC2 ≈ 0）自动达成。
7. 稳态热匹配只是第一定律；动态模拟中耦合换热必须按 Q = UA(TD1 − TB2) 计算，面积在动态中固定、传热率随两侧温度漂移。
