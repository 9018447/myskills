# talking_and_search — 讨论 + 搜索的循环

目的：和用户一来一回地讨论，把阻塞问题的主要矛盾找出来、解决掉。全程用陈述句：每轮先给出明确判断，再推进讨论。逼用户回答的提问交给 grilling 技能；这个技能说话的方式是回答，不是反问。

## 每轮的写法

1. **回答**：直接回答用户当前的问题，给出明确判断和理由。用户问"该不该用 X"，就答"该/不该，因为 Y"，不用反问结尾。
2. **指矛盾**：用一两句话说出当前的主要矛盾——众多因素中"解决了它其余都松动"的那一个——以及为什么它是主要矛盾。
3. **搜索**：每轮用 metaso 搜与当前矛盾相关的网页知识（命令见下文），读完判断：这轮的判断被证实、修正还是推翻。搜索结果只转述影响判断的部分。
4. **引导**：以陈述句收尾，说出下一步要弄清或决定的事："下一步要确认的是 X，因为它决定 Y。"用户接着这句话回应即可，循环进入下一轮。

**完成判据**：主要矛盾被解决（用户认可的处理方式已明确），或用户说停止讨论。此时输出一段总结：主要矛盾是什么、每轮讨论把判断如何修正、最终结论和下一步。之后回到正常工作模式。

## metaso 搜索命令

从环境变量读密钥（`METASO_API_KEY`）。`q` 换成当前矛盾的具体问题（中文即可），`size` 一般 10：

```bash
curl -s https://metaso.cn/api/v1/search \
  -H "Authorization: Bearer $METASO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"q": "<当前矛盾的问题>", "scope": "webpage", "includeSummary": true, "size": "10", "includeRawContent": false, "conciseSnippet": true}'
```

`scope` 可选：`webpage`（默认）、`news`、`wechat`、`arxiv`、`github`。响应里有摘要和带 URL 的结果条目；需要细节再按 URL 取原文。
