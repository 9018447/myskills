## Code Comments

- Do not add comments that merely describe what the code does.
- Do not add change-history comments. Git tracks history.
- Only comment on non-obvious design decisions, invariants,
  numerical assumptions, and essential workarounds.
- Preserve existing meaningful comments.
- Prefer self-explanatory code over explanatory comments.
