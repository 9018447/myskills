# Chapter 14: Radiation Heat Transfer

## Core Idea
辐射是与对流-导热并列的独立传热机制：一切高于绝对零度的物体均发射热辐射，净换热量正比于绝对温度四次方之差，工程计算的核心是把几何（视角因子 F）、表面性质（发射率 ε）与温度幂合并为一个总互换因子 𝓕，写进 $q=\sigma A\mathcal{F}(T_1^4-T_2^4)$。

## Frameworks Introduced
- **Stefan–Boltzmann law**：$W_b=\sigma T^4$——黑体总发射功率与绝对温度四次方成正比，是一切辐射计算的基准；σ = 5.672×10⁻⁸ W/m²·K⁴（0.1713×10⁻⁸ Btu/ft²·h·°R⁴）。
- **Planck's law**：给出黑体单色发射功率 $W_{b,\lambda}$ 随波长 λ 的完整分布，积分即得 Stefan–Boltzmann 定律。
- **Wien's displacement law**：$T\lambda_{max}=C$（C=2890 μm·K 或 5200 μm·°R）——温度越高，峰值波长越短；用于判断辐射落在可见/红外波段。
- **Kirchhoff's law**：热平衡下 $W/\alpha$ 仅是温度的函数，由此得平衡时 ε=α；仅对黑体、灰体（或平衡态）可外推到非平衡辐射交换。
- **Cosine law（diffuse radiation）**：完美漫射面发出的辐射强度 $dI=dI_0\cos\phi$，与观察方向的方向角余弦成正比——是推导视角因子的基础。
- **View factor（angle factor）F**：$q_{12}=\sigma A_1F_{12}(T_1^4-T_2^4)$，F₁₂ 为离开面 1 的辐射被面 2 拦截的份额；满足互易性 $A_1F_{12}=A_2F_{21}$ 与完整性 $F_{11}+F_{12}+F_{13}+\dots=1$。
- **Interchange factor $\bar{F}$**：当源与汇之间被耐火墙（再辐射面，净交换为零）连接时用 $\bar F$ 代替 F，近似式见 Eq. 14.33。
- **Overall interchange factor $\mathcal{F}$**：灰面间的总互换因子，同时计入几何与多次反射吸收，见 Key Equations。
- **Absorption length $L_\lambda$**：半透明材料中单色辐射衰减到 1/e 的穿透深度，$L_\lambda=1/\mu_\lambda$（μ 为吸收系数），由 Beer 型衰减律 $\frac{I_\lambda}{I_{0,\lambda}}=e^{-\mu_\lambda x}$ 定义；L ≫ L_λ 即"不透明"。
- **Radiation coefficient $h_r$**：把辐射线性化成对流形式的当量系数，用于辐射-对流并联复合传热。

## Key Concepts
- **Thermal radiation（热辐射）**：仅由温度引起的电磁辐射，工程上重要波段约 0.5–50 μm（红外为主）。
- **Blackbody（黑体）**：吸收全部入射辐射的理想体（α=ε=1），是所有辐射体的比较基准；实用近似为等温空腔小孔。
- **Gray body（灰体）**：单色发射率与波长无关的物体，其 ε=α 与角度无关——工程简化的重要假设。
- **Emissivity ε（发射率）**：物体总发射功率与同温黑体之比；抛光金属 0.03–0.08，氧化金属 0.6–0.85，非金属/油漆 0.65–0.96。
- **Absorptivity α / Reflectivity ρ / Transmissivity τ**：入射辐射被吸收/反射/透过的份额，$\alpha+\rho+\tau=1$；不透明固体 τ=0，吸收是表面现象。
- **Specular vs diffuse reflection**：镜面反射（入射角=反射角，抛光面）与漫反射（无确定方向，粗糙/无光面）；化工面多为漫反射。
- **Angle of vision（视角）**：接收表面对发射面元所张的立体角，最大 2π sr（半球）；凹面会"看见自己"（F₁₁>0）。
- **Refractory surface（再辐射面）**：吸收与再发射等量的中间面（净交换为零），把源没截住的能量转投给汇，如炉墙。
- **Greenhouse effect（温室效应）**：普通玻璃透短波（太阳 ~5500 K 源）、阻长波（室内 ~30°C 源），使封闭腔内温度升高。
- **Source / sink（源/汇）**：高温发射面与低温接收面，炉膛辐射计算的两大对象。

## Key Equations
- 灰面间净辐射（通用形式）：
$$q_{12}=\sigma A_1\mathcal{F}_{12}(T_1^4-T_2^4)$$
σ：Stefan–Boltzmann 常数；A₁：任选面 1 面积；𝓕₁₂：总互换因子（无量纲）；T₁、T₂：两表面绝对温度。
- 两个大灰平行平面（F=1）：
$$\mathcal{F}_{12}=\frac{1}{1/\varepsilon_1+1/\varepsilon_2-1}$$
ε₁、ε₂：两面发射率。
- 一个灰面被另一表面完全包围（如管道在房间里）：
$$\mathcal{F}_{12}=\frac{1}{1/\varepsilon_1+(A_1/A_2)[(1/\varepsilon_2)-1]}$$
A₁/A₂：内、外表面积比；外表面为大黑面（ε₂=1）时退化为 𝓕=ε₁。
- 含再辐射面的近似式（灰面+耐火墙通用）：
$$\mathcal{F}_{12}=\frac{1}{1/\bar{F}_{12}+[(1/\varepsilon_1)-1]+(A_1/A_2)[(1/\varepsilon_2)-1]}$$
- 视角因子互易与完整：
$$A_1F_{12}=A_2F_{21},\qquad F_{11}+F_{12}+F_{13}+\dots=1.0$$
- 复合传热（对流+辐射并联，黑环境）：
$$\frac{q_T}{A}=h_c(T_w-T)+\sigma\varepsilon_w(T_w^4-T^4)=(h_c+h_r)(T_w-T)$$
h_c：对流传热系数；h_r：辐射当量系数；T_w：壁温；T：环境温度；ε_w：表面发射率。
- 辐射系数近似（ΔT < 20%·T_w）：
$$h_r\approx 4\sigma\varepsilon_w T_w^3$$
（ΔT 稍大时用 $T_w,T$ 的算术平均温度代入）
- 膜态沸腾辐射修正（配合 Ch13 的 Eq. 13.22）：
$$h_c=h_o\left(\frac{h_o}{h_c+h_r}\right)^{1/3}$$
h_o：无辐射时的沸腾传热系数，需试差解 h_c。

## Worked Example
**例 14.1（辐射屏的温度与热流）**：涂黑漆铝板（ε₂=1.0）竖直置于两块钢板（ε₁=ε₃=0.56）之间，热板 300 °C（573 K）、冷板 25 °C（298 K），板距 150 mm，忽略对流。求铝板平衡温度与热流。
思路：① 两平行大平面 → 𝓕₁₂ = 1/(1/0.56+1/1.0−1) = 0.56，同理 𝓕₂₃=0.56；② 稳态时 q₁₂=q₂₃，面积相等，得 $T_1^4-T_2^4=T_2^4-T_3^4$（温度四次方线性插值），解得 T₂=490.4 K=217.4 °C；③ 热流 $q/A=5.672\times0.56\times(5.73^4-4.904^4)=1587\ \mathrm{W/m^2}$。
要点：一块 ε=1 的辐射屏把两板间热流从 3174 W/m² 降到 1587 W/m²——屏罩使温压四次方差减半、串联热阻相加。

## Anti-patterns
- **把 α 与 ε 任意互换**：Kirchhoff 定律仅在热平衡（或灰体）时成立；多数工业面非灰，α 随辐射源温度/峰值波长强烈变化（如低温源下纸、木、布 α 高，高温源下显著下降）。
- **漏掉视角因子或自见项**：凹面（如炉内管排后墙、腔体）F₁₁≠0；只有"看见彼此"的面积才参与直接交换， concave 面对自身辐射净交换为零。
- **对近距或封闭腔滥用距离平方反比**：q/A 才按 r² 衰减，总交换量 q 只取决于视角因子；有限大平行板必须查 F 图而非当作无穷平面。
- **气体一律视为透明或一律视为黑体**：O₂、N₂ 等单/双原子气体几乎不吸收红外；但 H₂O、CO₂、SO₂、烃类在炉温下于特定波带有强吸收，其 ε 取决于分压、路径长度与温度，还需 CO₂/H₂O 重叠修正。
- **h_r 当常数用**：h_r ∝ 4σεT³ 随温度三次方变化，只能在 ΔT < 20%·T_w 内近似；大温差必须回用四次方程。

## Key Takeaways
- 一切辐射净交换方程都归结为 $q=\sigma A\mathcal{F}(T_1^4-T_2^4)$；选对 𝓕（几何 F、再辐射 $\bar F$、灰体 𝓕 的正确组合）是全部工作量所在。
- 互易律 $A_1F_{12}=A_2F_{21}$ 与求和律 ΣF=1 是校核和推算未知视角因子的两个免费工具。
- 小物体被大空间包围（管路在车间内）：𝓕=ε₁，环境视为黑体即可；两面积接近时必须用完整式。
- 辐射-对流并联时用 (h_c+h_r) 线性化最方便，但 h_r 对温度极敏感，粗算 300 K 环境 ≈ 5–6 ε W/m²·°C 量级。
- 半透明介质用吸收长度 L_λ 判断：厚度 ≫ L_λ 即不透明（几毫米水层对 >1.5 μm 辐射 α≈1，可当黑体处理）。
- 膜态沸腾中辐射使汽膜变厚、h_c 下降，不能简单把 h_r 加到无辐射 h_o 上，需按 Eq. 14.50 试差。
