# Chapter 16: Evaporation

## Core Idea
蒸发是浓缩"非挥发溶质+挥发溶剂（多为水）"溶液的单元操作：单效计算归结为物料平衡 + 焓平衡 + $q=UA\Delta T$ 三件套；多效流程用蒸汽潜热逐级复用换取经济性，但总容量并不随效数增加——容量被 BPE（沸点升高）和总 ΔT 分配"吃掉"。

## Frameworks Introduced
- **单效焓平衡（无稀释热）**：$q=\dot m_fc_{pf}(T-T_f)+(\dot m_f-\dot m)\lambda$——蒸汽热 = 加热负荷（把料液升温到沸点）+ 蒸发负荷；T_f>T 时该项为负即闪蒸（flash evaporation）。
- **焓-浓度图（enthalpy–concentration diagram）**：强稀释热体系（NaOH、H₂SO₄、CaCl₂）的通用算法，H_f、H 读图，H_v 读蒸汽表，代入通用焓平衡 Eq. 16.4。
- **Dühring's rule**：给定浓度下，溶液沸点与同压纯水沸点呈直线关系——从水沸点+浓度线读出 BPE，是蒸发计算最实用的经验图。
- **多效 ΔT 分配规则**：稳态下 $q_1\approx q_2\approx q_3$ → $A_iU_i\Delta T_i$ 近似相等；等面积设计时 **各效温降与传热系数成反比**（$\Delta T_i\propto 1/U_i$）。
- **多效试差流程**：设各效沸点 → 焓平衡定各效流量 → 容量方程算面积 → 不等则修正温度迭代至等面积（实际由计算机完成）。
- **进料方式**：forward（顺流，效间自流免泵）、backward（逆流，逐效泵送，浓缩液黏度高时容量更大、但冷进料经济性差）、mixed、parallel（结晶蒸发器各效独立进料）。
- **Vapor recompression（蒸汽再压缩）**：把二次汽机械压缩（MVR）或蒸汽喷射热压缩（TVR）后返回本效蒸汽室，以少量功换取"准多效"经济性。

## Key Concepts
- **Capacity（容量）**：每小时蒸发水量 kg/h；**Economy（经济性）**：每 kg 生蒸汽蒸发的水量；蒸汽消耗 = 容量/经济性。单效 economy <1（1 kg 水需 1–1.3 kg 蒸汽），N 敛约 N。
- **Boiling-point elevation, BPE（沸点升高）**：同压下溶液沸点超出纯水的部分；稀溶液小，无机盐浓溶液可达 80 °C；每一效的 BPE 都从总 ΔT 中永久扣除。
- **Flash evaporation（闪蒸）**：过热进料进入低压空间自发绝热汽化，免费增加容量。
- **Falling-film evaporator（降膜蒸发器）**：液体沿大管（50–250 mm）内壁呈膜下行、一次通过；布膜均匀是成败关键（多孔板/蜘蛛式分配器/管内喷嘴）；最适合热敏与黏性物料；要求降膜 Re=4Γ/μ>2000，过度浓缩会产生干斑。
- **Climbing-film / long-tube vertical（升膜长管式）**：管内气液并流上升，25–50 mm 管、3–10 m；能靠高速冲击挡板破碎泡沫；只能循环式操作。
- **Forced-circulation evaporator（强制循环）**：泵送 2–5.5 m/s，静压头抑制管内沸腾，闪蒸发生在换热器出口；管内停留仅 1–3 s；适合黏性、结垢、盐析物料；稀薄液体不值得多耗泵功。
- **Agitated-film evaporator（刮膜式）**：单根夹套管+转子叶片强制成薄湍流膜，可处理黏度高达 1000 P 的物料；系数按 Eq. 15.23 估算；贵、单机容量小、有维修量。
- **Once-through vs circulation**：一次通过式（降膜/刮膜）停留时间短，适合热敏物料；循环式池内液体全在最终浓度、黏度高系数低，不适合热敏物料但单机浓缩跨度大。
- **Liquid head（液柱静压）**：液层深度+管内摩擦使平均沸点高于汽相空间压力对应值，压低有效 ΔT；液位高、流速快时不可忽略。
- **Mechanical vs thermal recompression**：MVR 最优 ΔT≈5 °C，折合 10–15 效经济性，适合海水淡化/黑液/果汁；TVR 用 8–10 atm 生蒸汽引射，蒸汽/蒸发量比约 0.5，便宜耐真空但效率低、操作弹性差。

## Key Equations
- 容量方程：$q=UA\Delta T$（U：总系数；A：传热面；ΔT：经 BPE 修正的净温差）。
- 蒸汽侧焓平衡：$q_s=\dot m_s(H_s-H_c)=\dot m_s\lambda_s$（λ_s：蒸汽冷凝潜热；ṁ_s：蒸汽流量）。
- 液侧通用焓平衡（含稀释热）：
$$q=(\dot m_f-\dot m)H_v-\dot m_fH_f+\dot mH$$
H_v：离开蒸汽（常按汽相空间压力的饱和汽处理）；H_f、H：进料/浓液比焓。
- 无稀释热时的实用式：
$$q=\dot m_fc_{pf}(T-T_f)+(\dot m_f-\dot m)\lambda$$
c_pf：进料比热；λ：汽相空间压力下水的汽化潜热。
- 多效 ΔT 分配（等面积）：
$$U_1\Delta T_1=U_2\Delta T_2=U_3\Delta T_3=\frac qA\;\Rightarrow\;\Delta T_i=\frac{1/U_i}{\sum_j(1/U_j)}\Delta T_{total}$$
- 强制循环液侧系数：用 Eq. 12.33 形式但常数由 0.023 改为 **0.028**。

## Worked Example
**例 16.1（单效 NaOH，用焓-浓度图）**：20,000 lb/h 的 20% NaOH 浓缩到 50%；蒸汽 20 psig（T_s=259 °F），汽相空间 100 mmHg；U=250 Btu/ft²·h·°F；进料 100 °F。步骤：① 物料平衡：每磅固体带走水 4−1=3 lb → 蒸发 12,000 lb/h，浓液 8,000 lb/h；② 沸点：水在 100 mmHg 沸点 124 °F，Dühring 线读 50% 浓液沸点 197 °F → BPE=73 °F；③ 焓平衡（16.4）：H_f=55、H=221（焓-浓度图）、H_v=1149（197 °F 过热汽）、λ_s=939 → q=14.46×10⁶ Btu/h；④ 蒸汽 15,400 lb/h，economy=0.78，A=q/[U(T_s−T)]=930 ft²。附注：H_v 用饱和汽近似仅差约 3%——工程可接受。

## Anti-patterns
- **以为多效增加容量**：N 效总容量 ≈ 单效（同单效面积、同端点条件）；因为总 ΔT 被 N 等分，单位面积蒸发量约为 1/N。多效买的是 economy，不是 capacity。
- **漏加 BPE 或在多效中漏加每效 BPE**：温差要从蒸汽室压力对应的**饱和蒸汽温度**算起，而不是上一效沸腾液温度；汽化蒸汽过热度对传热几乎无益。极端情形 ΣBPE > 总 ΔT 时设备根本无法操作。
- **有稀释热还用比热式**：NaOH、H₂SO₄、CaCl₂ 等浓溶液稀释热显著，必须用焓-浓度图（Eq. 16.4）；糖、盐、纸浆黑液等可安全用 c_p 法。
- **忽略液柱静压与管内摩擦**：深液位自然循环单元的有效 ΔT 可被吃掉相当比例，定性上必须预留。
- **热敏物料选循环式**：池式循环中部分液体长期反复过热，"平均停留时间短"不能保证全部物料安全；热敏物料用一次通过降膜/刮膜+高真空。
- **经济性当传热问题算**：economy 由焓平衡决定、与 BPE 基本无关；capacity 才受 U 和 ΔT 支配。二者别混。

## Key Takeaways
- 蒸发器选型由**料液特性**主导：起泡→升膜（撞板破泡）；热敏→降膜一次通过；黏稠→强制循环/刮膜；结垢盐析→强制循环（管内不沸腾）。
- 设计三件套：物料平衡定蒸发量 → 焓平衡定蒸汽量 → q=UAΔT 定面积；等面积多效用 ΔTᵢ∝1/Uᵢ 分配温降再试差迭代。
- BPE 是多效系统的"隐形税"：每效扣一次；效数上限由 ΣBPE 与总 ΔT 的比较决定。
- 多效效数是最优经济问题：省蒸汽 vs 多 N 倍投资，不是效数越多越好。
- MVR 经济性 ≈ 10–15 效、最优 ΔT≈5 °C，是低 BPE、大规模蒸发（海水、黑液、果汁）的省能首选；TVR 适合真空场合。
- 非冷凝气体在蒸汽室累积会毁掉蒸汽侧膜系数——蒸汽室必须设排气，负压运行必须防漏气。
