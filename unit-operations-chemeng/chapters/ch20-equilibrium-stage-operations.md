# Chapter 20: Equilibrium-Stage Operations

## Core Idea
把多级逆流接触设备（级联 cascade）抽象为"理想级"序列：进出各级的两相不互成平衡以提供推动力，离级两相**假设**达平衡，再用级效率校正。本章建立级数编号、物料/焓平衡通式、操作线-平衡线图解法（McCabe-Thiele 雏形）与直线体系下的 Kremser 解析法。

## Frameworks Introduced
- **Cascade（级联）与理想级假设**：离开同一级的 V 相与 L 相互成平衡（perfect plate）；实际级数 = 理想级数 / 级效率。
- **Operating-line diagram（操作线图）**：二元体系以 $x$-$y$ 作图，操作线连接 $(x_n, y_{n+1})$ 点集；操作线与平衡线的相对位置决定传质方向——精馏：操作线在平衡线**下方**；吸收：**上方**；解吸/汽提：下方（且平衡线更陡）。
- **McCabe-Thiele 阶梯法**：在操作线与平衡线间交替作水平/垂直线逐级数出理想级；可从任一端开始，末级允许分数级。
- **Kremser equation（吸收因子法）**：操作线与平衡线均为直线时解析求 N：$A = L/(mV)$（吸收因子），$S = mV/L = 1/A$（汽提因子）。
- **Stage numbering convention**：按 L 相流动方向编号，第 n 级流出物流标下标 n；$y_{n+1}$ 与 $x_n$ 同属一个平衡截面。

## Key Concepts
- **Ideal stage / perfect plate**：离级气液两相互成平衡的假想接触级，是实际级的比较基准。
- **Stage (plate) efficiency**：实际级接近理想级的校正系数（Ch. 21 详述）。
- **Reflux（回流）**：塔顶冷凝液部分返回，使上升蒸气逐级增浓；再沸器产生的蒸气须同时提供回流与塔顶产品——精馏能耗的主体。
- **Rectifying section / stripping section**：进料板以上的提浓段（蒸气增浓低沸物）与以下的汽提段（液体逐级脱除低沸物）。
- **Absorption factor $A = L/(mV)$**：操作线斜率与平衡线斜率之比；设计吸收时通常取 $A > 1$。
- **Stripping factor $S = mV/L$**：其倒数关系；汽提设计通常取 $S > 1$。
- **$y^*$、$x^*$**：与指定另一相浓度成平衡的虚拟浓度，构成 Kremser 式中的推动力项。
- **Sieve plate**：开孔塔板 + 降液管 + 堰，气液在板上鼓泡/泡沫接触；雾沫夹带影响级效率。

## Key Equations
- 级间物料平衡（前 n 级）：$L_a x_a + V_{n+1} y_{n+1} = L_n x_n + V_a y_a$
- 操作线方程：$y_{n+1} = \dfrac{L_n}{V_{n+1}} x_n + \dfrac{V_a y_a - L_a x_a}{V_{n+1}}$；恒 L/V 时为直线，端点 $(x_a, y_a)$、$(x_b, y_b)$
- 焓平衡（绝热、无功）：$L_a H_{L,a} + V_{n+1} H_{V,n+1} = L_n H_{L,n} + V_a H_{V,a}$
- 吸收因子：$A \equiv L/(mV)$；汽提因子：$S \equiv mV/L$
- **Kremser equation**（吸收型，$A \ne 1$）：
$$N = \frac{\ln\left[(y_b - y_b^*)/(y_a - y_a^*)\right]}{\ln\left[(y_b - y_a)/(y_b^* - y_a^*)\right]}$$
（$y_b$=进口气浓度，$y_a$=出口气浓度；$y^*$=与对应液相成平衡的气相浓度）
- $A=1$（两线平行）特例：$N = (y_b - y_a)/(y_a - y_a^*)$（推动力恒定）
- $A<1$ 时取倒数形式；设计已有塔的反算：$A^N = (y_b - y_b^*)/(y_a - y_a^*)$
- 汽提型（x 基准）：$N = \dfrac{\ln[(x_a - x_a^*)/(x_b - x_b^*)]}{\ln S}$，反算 $S^N = (x_a - x_a^*)/(x_b - x_b^*)$
- 平衡线：$y_e = m x_e + B$（B≠0 也可用，只要求计算区间内线性）

## Reference Tables
| 操作 | 操作线位置（相对平衡线） | 因子设计取值 |
|---|---|---|
| 精馏 rectification | 下方 | — |
| 吸收 absorption | 上方 | $A > 1$（操作线更陡） |

## Worked Example
**Ex. 20.1（变流量吸收的操作线作图）**：板式塔用无挥发油吸收空气中的丙酮：进口气 30 mol% 丙酮，油无丙酮，吸收 97%，釜液 10 mol% 丙酮，$y_e = 1.9 x_e$。以 100 mol 进气为基准做物料衡算：$y_a = 0.0127$、$L_b = 291$、$L_a = 261.9$；因气液流量沿塔变化，用分段衡算取中间点（如 y=0.125 → x=0.0336；y=0.222 → x=0.068）——操作线仅微弯（气量变化近 30% 但 L/V 变化小）。阶梯得 4.3 个理想级（分数级按 x 或 y 方向线段比折算，两者略有差异因两线不平行）。

**Ex. 20.2（Kremser 反算）**：稀氨水空气汽提，7 块筛板，$y_e = 0.8 x_e$，V/L=1.5 时除氨 90%。$S = 0.8×1.5 = 1.2$；代入汽提型 Kremser 式得 N = 5.02 理想级 → 全塔效率 5.02/7 = 72%。若 V/L 增至 2.0（S=1.6，N 不变），由 $S^N$ 反解得除氨率升至 96.2%。

## Anti-patterns
- **把进出同一级的两股物料当平衡对**：平衡是"离开同级"的 $x_n$ 与 $y_n$；操作线关联的是 $x_n$ 与 $y_{n+1}$（错位一级），这是阶梯法容易数错级的根源。
- **对变流量体系强行用直线操作线端点连直线**：吸收中 L 增 V 减，操作线微弯；应补 1–2 个中间衡算点，但 L/V 变化远小于 L、V 各自变化，故常近直线。
- **用 $A<1$ 做高回收率吸收设计**：$A<1$ 时存在回收率上限（出口浓度趋于与进口液平衡），要近完全回收必须 $A>1$。
- **Kremser 式外推到平衡线弯曲区间**：只在直线区间有效；可用区间内拟合直线近似，但不可跨曲率变化大的范围。
- **忘记组元 B 平衡不独立**：总衡算减 A 组元衡算即 B 衡算，独立方程只有两个。

## Key Takeaways
1. 级式设备设计流程：理想级数 N（图解或 Kremser）→ 实际级数 = N/效率；本章只做理想级。
2. 操作线-平衡线相对位置 = 传质方向的几何表达；"哪条在上"按组分从哪相传入哪相判断，不靠死记。
3. Kremser 三变量 N、A（S）、端浓度知二求一：设计求 N，运行分析反算浓度（$A^N$、$S^N$ 形式最实用）。
4. 早期汽提用 x 基准公式更顺；萃取/浸取可用摩尔比或质量比浓度，只要两线仍直。
5. 多组分体系图解失效，改用逐级代数迭代或计算机严格计算（Ch. 22）。
6. 塔内总摩尔蒸气流量近似恒定（低沸物蒸发潜热由高沸物冷凝潜热供给）——这是恒摩尔流假设的物理来源。
