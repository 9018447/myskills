# Chapter 24: Drying of Solids

## Core Idea
干燥是用热汽化把固体中少量液体降到合格水平的热分离操作：设备按固体受热方式（直接/间接/介电辐射）与运动模式分类，但设计核心都归到"湿含量驱动的速率曲线"——恒速段由外部气相传热传质控制（界面≈湿球温度），降速段由内部水分流动控制。

## Frameworks Introduced
- **Dryer classification**：direct/adiabatic（热气流直接接触：cross-circulation、through-circulation、shower/rotary、fluidized、pneumatic/flash）vs indirect/nonadiabatic（间接加热面：tray 真空、screw-conveyor、drum、thin-film）vs dielectric/radiant/microwave；direct-indirect 组合式。
- **Free vs equilibrium moisture**：$X = X_T - X^*$——干燥计算只关心自由水分；$X^*$ 由进气相对湿度决定（平衡-湿度曲线近似与温度无关），出料湿含量不可能低于它。
- **Bound vs unbound water**：与 100% RH 曲线交点为界；bound water 蒸汽压低于同温纯水（细毛细凹面、细胞壁溶解物），unbound water 承受全蒸汽压。bound/unbound 是物料属性，free/equilibrium 是操作条件属性。
- **Rate-of-drying curve（速率曲线）**：恒速段（表面全湿，$R_c$ = 自由液面蒸发速率）→ 第一降速段（湿表面收缩，近线性）→ 第二临界点/第二降速段（孔隙空气成为连续相、孤立液池，扩散控制，曲线上凹）；陶瓷板等可出现两个降速段。
- **Critical moisture content（临界湿含量 $X_c$）**：恒速段结束点，是物料特性 × 料层厚度 × 干燥强度的综合结果（非纯物性）；初湿低于 $X_c$ 则无恒速段；减薄料层降低 $X_c$。
- **Internal moisture transport**：非多孔固体按扩散模型（慢干物料，表面≈平衡湿含量，风速几乎无影响）；多孔固体靠毛细力（细孔从粗孔拉水，大孔先空）与表面扩散；case hardening（表面硬化）是快速干燥收缩的失效模式。
- **Drying-time integration**：$t_T = \frac{m_s}{A}\int_{X_2}^{X_1}\frac{dX}{R}$；恒速段 $t_c = \frac{m_s(X_1 - X_c)}{AR_c}$；R 与 X 线性时用 $\frac{1}{a}\ln(R_c/R_2)$；全段单直线过原点时 $t_T = \frac{m_s}{AR_c}\left(X_1 - X_c + X_c\ln\frac{X_c}{X_2}\right)$。
- **NTU rating of adiabatic dryers**：$N_t = \ln\frac{T_{hb} - T_{wb}}{T_{ha} - T_{wb}}$（空气-水体系）；转筒干燥器最经济区间 $N_t = 1.5 \sim 2.5$，据此反推出口气温。
- **Freeze-drying（lyophilization）**：升华界面温度由干燥层导热与蒸汽外扩的耦合平衡决定（类比湿球温度，但阻力随时间增大）；干燥时间 ∝ 料层厚度²，常需数小时。

## Key Concepts
- **优先机械脱水**：机械除水（压滤/离心）远比热汽化便宜，进干燥器前尽量降低湿含量；"干燥"只是从初值降到合格值的相对概念（盐 0.5%、煤 4%、干酪素 8%）。
- **Vaporization temperature $T_v$**：无 sweep 气的间接干燥器≈操作压下液体沸点；绝热干燥器≈气体湿球温度（空气-水体系即绝热饱和温度）。盘式干燥器的辐射/导热使 $T_i > T_{wb}$，但系数计算仍取 $T_h - T_{wb}$ 为推动力。
- **Duty breakdown（Eq. 24.1）**：加热料、汽化、加热干固体、加热蒸汽四项，多数场合汽化项主导；绝热干燥器热量全部来自气体降温 $q_T = \dot m_g c_{sb}(T_{hb} - T_{ha})$。
- **Through-circulation 优势**：穿流比横流面积放大（颗粒全表面有效）+ 扩散距离缩短；Ex. 24.1→24.2 中单位时间处理量提高 20 倍以上，干燥时间缩短到 <2%。
- **Flash/spray drying**：悬浮颗粒干燥 0.5–5 s 内完成，恒速/降速概念失去意义；进口气温可高达 650°C 但固体升温 <50°C，适合热敏物料。
- **Spray-dry economics**：单机替代蒸发-结晶-过滤-干燥-粉碎-筛分全流程，产物多孔空心球（溶质向表面富集）；缺点是热效率低、设备高大（~25 m）、堆密度难控。
- **Selection logic**：<150–200 kg/h 批式，>1–2 t/h 连续；热敏→低温/真空/闪蒸喷雾；易碎晶体→托盘/网带/塔式；细粉或活性高→间接式；绝热式虽便宜但除尘系统可吃掉优势。

## Key Equations
- 总热负荷：$\dfrac{q_T}{\dot m_s} = c_{ps}(T_{sb} - T_{sa}) + X_a c_{pL}(T_v - T_{sa}) + (X_a - X_b)\lambda + X_b c_{pL}(T_{sb} - T_v) + (X_a - X_b)c_{pv}(T_{va} - T_v)$
- 恒速段速率：$R_c = \dfrac{\dot m_v}{A} = \dfrac{h_y(T - T_i)}{\lambda_i}$（或传质式 $\dot m_v = \frac{M_v k_y(y_i - y)A}{(1-y)_L}$）
- 平行流系数（空气，Re 2600–22000）：$h_y = \dfrac{8.8G^{0.8}}{D_e^{0.2}}$（SI，W/m²·°C）；垂直冲击流（0.9–4.5 m/s）：$h_y = 24.2G^{0.37}$
- 干燥时间通式：$t_T = \dfrac{m_s}{A}\displaystyle\int_{X_2}^{X_1}\dfrac{dX}{R}$；恒速段 $t_c = \dfrac{m_s(X_1 - X_c)}{AR_c}$；线性降速段 $t_f = \dfrac{m_s}{aA}\ln\dfrac{R_1}{R_2}$，$a = \dfrac{R_c - R'}{X_c - X'}$
- 单直线近似总时间：$t_T = \dfrac{m_s}{AR_c}\left(X_1 - X_c + X_c\ln\dfrac{X_c}{X_2}\right)$
- 干燥器传热单元：$N_t = \int_{T_{ha}}^{T_{hb}}\dfrac{dT_h}{T_h - T_s} = \ln\dfrac{T_{hb} - T_{wb}}{T_{ha} - T_{wb}}$（空气-水）
- 转筒干燥器经验式：$q_T = \dfrac{0.5G^{0.67}}{D}V\overline{\Delta T} = 0.125\pi DLG^{0.67}\overline{\Delta T}$，$U_a = \dfrac{0.5G^{0.67}}{D}$（fps）
- 喷雾盘雾滴 Sauter 直径：$\dfrac{\bar D_s}{r} = 0.4\left(\dfrac{\Gamma}{\rho_L n r^2}\right)^{0.6}\left(\dfrac{\mu}{\Gamma}\right)^{0.2}\left(\dfrac{\sigma\rho_L L_p}{\Gamma^2}\right)^{0.1}$；干燥时间按**最大液滴 ≈ 2$\bar D_s$**计算
- 颗粒-气体传热（流化/悬浮）：$\dfrac{h_oD_p}{k_f} = 2.0 + 0.60\left(\dfrac{D_pG}{\mu_f}\right)^{0.5}\left(\dfrac{c_p\mu_f}{k_f}\right)^{1/3}$，低速极限 Nu≈2.0

## Worked Example
**Ex. 24.3（回转干燥器完整设计）**：2800 lb/h 热敏固体从 15%→0.5%（干基），$c_{ps}=0.52$，进料 80°F、上限 125°F；空气 260°F、$\mathcal H=0.01$、$G_{max}=700$ lb/ft²·h。选并流：取 $N_t=1.5$ → $T_{ha} = 102 + (260-102)e^{-1.5} = 137°F$（$T_{wb}=102°F$）；Eq. 24.1 负荷 179.3 Btu/lb（汽化项 150.2 主导）→ $q_T = 502{,}040$ Btu/h；热衡算得风量 16,495 lb/h 干空气；由 G 上限定径 $D = \sqrt{4\times23.8/\pi} = 5.50$ ft；$\overline{\Delta T} = $ 湿球降对数均值 81.6°F，Eq. 24.23 反算 $L = 36$ ft，L/D=6.5 合理。**设计链：N_t 定出口气温 → 焓衡算定风量 → G 上限定径 → U_a 经验式定长。**

（Ex. 24.1 恒速横流盘干：$h_y = 0.01\times1972^{0.8}/0.5^{0.2} = 4.97$ → $R_c = 0.379$ lb/ft²·h，20%→10% 双面干燥 2.64 h；Ex. 24.2 同料挤条穿流：床层出口风温 15.8°F 差、$\overline{\Delta T_L} = 39.6°F$、$q_T = 14{,}500$ Btu/h → **3.47 min**，约为横流的 1/50。）

## Anti-patterns
- **不先做机械脱水就进热干燥器**：压滤/离心除水远比汽化便宜；热干燥只处理最后残余水分。
- **忽略进风湿度对 $X^*$ 的锁定**：出料湿含量不可能低于与进风 RH 平衡的平衡水分（30% RH 的空气干燥毛线最低到 9%）；盲目延长时间徒劳。
- **把 $X_c$ 当纯物性查表使用**：它随料层厚度、干燥强度、内外阻力分配变化；设计与实验条件不符时须重测。
- **按平均液滴直径设计喷雾干燥**：必须按最大液滴（≈2 倍 Sauter 平均）完全蒸发来定停留时间，否则产品含湿。
- **转筒干燥器操作点偏离 $N_t = 1.5\sim2.5$**：出口气温过高浪费能量，过低则完成不了干燥；出口气湿球温度必须与进口湿球一致（绝热线自校核）。
- **热敏物料用低温介质却忽略流化床的温度均一性**：流化床内颗粒几乎被加热到出口干球温度——热敏物料要么降低整体气温，要么用闪蒸/喷雾靠接触时间短保护。
- **只算干燥器不算整个隔离系统**：绝热干燥器的除尘设备可能比干燥器本身还贵；溶剂湿物料应优先封闭式间接干燥器回收溶剂。

## Key Takeaways
1. 干燥设计的两条主线：热负荷（Eq. 24.1，汽化项主导）与干燥时间（速率曲线积分）；恒速段用传热系数 + 湿球推动力，降速段用实测速率曲线或线性近似。
2. 恒速段速率与自由液面蒸发相同（$R_c = h_y(T-T_{wb})/\lambda$），界面即湿球温度；穿过边界层的总推动力是 $T_h - T_{wb}$，即使真实 $T_i$ 略高也如此处理。
3. 穿流（through-circulation）对横流的加速是数量级的：颗粒全表面参与传热传质 + 内扩散距离缩短；膏状物料先挤条/造粒预成型。
4. 多孔固体两段降速的物理图像：第一段湿区从大孔退却（速率仍受外部条件控制、近线性），第二段空气成连续相、汽化转入内部（扩散控制、与风速无关、曲线上凹）。
5. 绝热干燥器用 NTU 框架做经济优化：转筒 $N_t = 1.5\sim2.5$；并流保护热敏物料（进口端高温对湿料），逆流提高出口固体温度上限。
6. 设备选型由物料形态与热敏性主导：溶液/浆料一步到干用喷雾/转鼓/薄膜；颗粒大宗用回转/流化床；热敏用闪蒸/喷雾/冷冻干燥；细粉与溶剂回收用间接式。
7. 冷冻干燥是"热通过干燥层的导热 vs 蒸汽通过干燥层的扩散"的稳态平衡，干燥时间近似与料厚平方成正比——薄层装料是唯一提速手段。
