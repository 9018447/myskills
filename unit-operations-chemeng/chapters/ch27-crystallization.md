# Chapter 27: Crystallization

## Core Idea
结晶是均相内生成固相粒子的过程：产率由溶解度与焓衡算决定，而产品晶体的尺寸分布（CSD）由成核速率与生长速率的耦合动力学决定；工业设计的核心是用低过饱和度 + 接触成核 + 细晶控制来操纵 CSD。

## Frameworks Introduced
- **Magma（晶浆）**：结晶器内母液与各尺寸晶体的两相混合物，是结晶装置的"工艺对象"。
- **Invariant growth（不变性生长）**：理想晶体生长保持几何相似；特征长度 L=6v_p/s_p，实践中取筛析尺寸。
- **三种产生过饱和度的方式**：冷却（溶解度随温度陡升型）、蒸发溶剂（NaCl 型或倒溶解度型）、加第三组分（salting/沉淀）——"选方式前先看溶解度曲线形状。"
- **接触成核（contact nucleation）**：晶体与叶轮/晶体/壁面低能碰撞（几百 erg）产生新核；速率 ∝ 过饱和度一次方，是工业结晶器的主导成核机制（低过饱和操作下均相成核几乎不可能发生）。
- **两步生长模型**：扩散（k_y）+ 表面反应（k_s）串联，总系数 K=1/(1/k_y+1/k_s)；界面浓度 y' 介于 y 与 y_s 之间。
- **ΔL 定律（McCabe）**：均匀过饱和场中所有晶体以相同速率 G 生长，ΔL=GΔt 与尺寸无关；严格适用区间约 50–500 μm。
- **MSMPR 模型（mixed suspension–mixed product removal）**：8 条假设（稳态、全混、均匀过饱和、ΔL 律、无分类排料等）推出 n=n°e^{-z}，z=L/(Gτ)，是 CSD 计算的通用骨架。
- **细晶消除与双出料（DDO）**：细晶溶解除去→提高平均粒径；DDO 用溢流/底流分流（典型 8–12:1）使大晶停留时间延长约 10 倍，平均粒径达 MSMPR 的 2–3 倍。
- **熔融结晶（melt crystallization）**：共晶体系冷却即得近纯晶体；Brodie 提纯器用"熔融回流洗涤柱"把表面附着与包藏母液洗出。

## Key Concepts
- **Supersaturation s**：分数过饱和度 Δc/c_s=Δy/y_s；工业实践通常 <2%——过饱和度既是生长与成核的共同推动力，又是需要压制的"火药"。
- **Ostwald ripening（奥斯特瓦尔德熟化）**：微米以下小晶体溶解度更高，与过饱和溶液可处于不稳定平衡；有共存大晶时小晶溶解消失。
- **Kelvin 方程**：ln α=4V_Mσ/(νRTL)——晶核临界尺寸与过饱和度的热力学桥梁；用 σ_a（表观界面张力，KCl 约 2–3 erg/cm²）代替真实 σ（80–100 erg/cm²）描述多相/次级成核。
- **Veiled growth / needle breeding**：过饱和度过高导致雾状包藏或针状枝晶——劣质晶体的两个典型来源。
- **Initial breeding**：晶种表面携带的微晶洗脱成核，用不饱和液"驯化"晶种可避免。
- **Screw dislocation（Frank 螺位错）**：解释生长速率与过饱和呈线性且无阈值——螺旋台阶永不断裂，永远提供生长扭结。
- **Population density n**：单位体积母液、单位长度区间的晶体数 d(N/V)/dL；半对数图 ln n–L 直线斜率 −1/Gτ，是实验测定 G 与 B° 的标准手段。
- **Predominant size L_pr**：质量分布峰值处，L_pr=3Gτ——设计者用 τ（停留时间）与 G 直接换算目标粒径。
- **DTB crystallizer（导流筒-挡板）**：内循环桨+环隙澄清区除细晶+淘析腿分级出料；清液循环使晶浆密度达 30–50%（沉降晶体积/总晶浆体积）。
- **Center-of-gravity principle（重心原理）**：两相混合物中各相质量与其浓度差成反比，用于焓-浓图上快速求晶浆 split。

## Key Equations
- 特征长度：$L=\dfrac{6v_p}{s_p}=\Phi_s D_p$（v_p=晶体体积，s_p=表面积，Φ_s=球形度）
- 过饱和度换算：$\Delta c=\rho_M\Delta y$；$\alpha\equiv c/c_s=1+s$（ρ_M=溶液摩尔密度；s=分数过饱和）
- 温度势当量：$\Delta T_c=\kappa\Delta y=\dfrac{\kappa}{\rho_M}\Delta c$（κ=T–y 溶解度曲线斜率）
- Kelvin 方程：$\ln\alpha=\dfrac{4V_M\sigma}{\nu RTL}$（V_M=晶体摩尔体积，σ=固液界面张力，ν=每分子溶质离子数，L=晶体尺寸）
- 初级成核速率：$B^{\circ}=C\exp\Big[-\dfrac{16\pi\sigma^3V_M^2\mathbf{N}_a}{3\nu^2(RT)^3(\ln\alpha)^2}\Big]$（C≈10²⁵ nuclei/cm³·s；指数项主导，速率对 s 极端敏感）
- 多相成核（以 σ_a 代 σ）：$B^{\circ}=10^{25}\exp\Big[-\dfrac{16\pi V_M^2\mathbf{N}_a\sigma_a^3}{3(RT)^3\nu^2s^2}\Big]$
- 生长总系数与线生长速率：$K=\dfrac{1}{1/k_y+1/k_s}$；$G=\dfrac{2K(y-y_s)}{\rho_M}$（k_y=传质系数，k_s=表面反应系数，G=dL/dt）
- ΔL 定律：$\Delta L=G\Delta t$
- 群体密度分布：$n=\dfrac{d(N/V)}{dL}$；MSMPR 解 $n=n^{\circ}e^{-z}$，$z=\dfrac{L}{G\tau}$（n°=核群密度，τ=停留时间）
- 动力学耦合：$B^{\circ}=Gn^{\circ}$
- 单位质量晶粒数：$\dfrac{n_c}{m_c}=\dfrac{1}{6a\rho_c(G\tau)^3}=\dfrac{9}{2a\rho_cL_{pr}^3}$（a=形状因子，ρ_c=晶体密度，L_pr=3Gτ）
- 所需成核速率：$B^{\circ}=\dfrac{9C}{2a\rho_cV_cL_{pr}^3}$（C=晶体产量 kg/h，V_c=器内液体体积）
- 接触成核模型（Bennett 等）：$B^{\circ}=K_Nn^{\circ}G\dfrac{u_T^2}{t_{To}}\rho_c(G\tau)^5$（u_T=叶尖速度，t_To=翻转时间；实测 KCl 中 B°∝G^2.77·m_c^0.91）
- 蒸发-冷却物料焓衡算（真空结晶器）：进料、蒸气、晶浆三点共线于焓-浓图；绝热闪蒸。

## Reference Tables
- **成核速率对 s 的爆炸性响应（KCl，σ_a=2.5 erg/cm²，300 K）**：s=0.023→B°=4.5×10⁻⁵；s=0.025→1；s=0.027→5.0×10³；s=0.029→3.5×10⁶ nuclei/cm³·s——s 变化 ±0.002 覆盖 11 个数量级，说明初级成核在工业中不可用。
- **晶核平衡尺寸**：s=0.029、σ_a=2.5 时 Kelvin 求得 L=2.63 nm（几百个分子）；若用真实 σ=80 erg/cm² 则需 s=1.5（150%），证明溶液结晶的均相成核不可能。
- **过饱和-生长质量分区（MgSO₄·7H₂O）**：T_s−1℃ 良好生长无成核（最佳操作区）；T_s−4℃ 雾状生长；T_s−8℃ 枝晶/碎裂；T_s−16℃ 多相成核——ΔT 是控制旋钮。
- **MSMPR 矩分布节点**：数量峰 z→0（永远偏小晶）；尺寸峰 z=1；面积峰 z=2；质量峰（主导粒径）z=3。
- **设备通量**：DTB 晶浆密度 30–50%；DDO 溢流:底流 ≈8–12:1；MSMPR 主导粒径由 τ=L_pr/3G 反推器体积。

## Worked Example
**Ex 27.1（水合物产率）**：30% MgSO₄ 溶液冷至 60°F、蒸发 5% 水；全部换算为 MgSO₄·7H₂O+自由水基准，母液 24.5% MgSO₄ 对应自由水比 50.16/49.84，1000 kg 进料得 261 kg 晶体——自由水基准是水合物产率计算的万能钥匙。
**Ex 27.2（焓-浓图算热负荷）**：32.5% MgSO₄ 从 120°F 冷到 70°F（无蒸发）：Δh=−45.4 Btu/lb 溶液，重心原理求出 28.8 lb 晶体/100 lb 浆，315,000 Btu/ton 晶体——焓-浓图+重心原理双件套。
**Ex 27.3（成核速率曲线）**：由 Eq. 27.10 生成 B°–s 表，展示"1 nucleus/cm³·s 阈值 s=0.025"两侧的天壤之别。
**Ex 27.4（Kelvin 求晶核尺寸）**：s=0.029 的 KCl 平衡晶核 2.63 nm，与"几百个分子"的图景自洽。
**Ex 27.5（真空结晶器全衡算）**：31% MgSO₄ 进料、86°F 平衡（沸点升高 2°F）、5 ton/h 晶体：焓图三点共线得进料 130°F、蒸发 2017 lb/h、进料 56,537 lb/h。
**Ex 27.6（MSMPR 设计）**：G=0.0018 ft/h、20-mesh 产品 → τ=0.506 h、器内液量 273 ft³（浆 321 ft³）、B°=7.7×10⁷ nuclei/ft³·h、n°=4.3×10¹⁰ ft⁻⁴；由矩方程读出完整筛析（20-mesh 处累计 35%）。

## Anti-patterns
- **用高过饱和度提产量**：B° 随 s 指数爆炸→细晶洪水→表面面积暴增→过饱和被稀释→单晶生长停滞；产量问题永远用"减少晶核数"解决，不用"提高过饱和度"。
- **只按溶解度曲线算产率**：慢生长或晶体沉底时母液残留过饱和，实际产率低于计算值。
- **水合物产率按无水盐基准直接相减**：结晶水不可参与溶解溶质；必须以水合物+自由水基准衡算。
- **忽略真空结晶器的静液位效应**：300 mm 静压头把 7.6 mmHg 沸点抬到 29℃——进料点低于液面即不闪蒸（也可反过来利用：在液面下进料控制成核）。
- **无搅拌的简单真空结晶器**：表面附近过饱和、底部无过饱和、晶体沉降；且无成核控制、无分级、无细晶消除手段。
- **以数量分布评价产品**：数量永远偏小晶；设计判据应基于质量分布（L_pr=3Gτ）。
- **单出料想放大粒径**：MSMPR 的上限由 Gτ 锁死；要 2–3 倍平均粒径必须细晶消除或 DDO 分类（石膏废浆 DDO 后从"不可过滤的泥"变"像沙子一样过滤"）。

## Key Takeaways
- 结晶的双重目标：产率靠热力学（溶解度+焓衡算），CSD 靠动力学（B° 与 G 的竞争）——守恒定律本身分不出"一颗大晶"和"一浆碎晶"。
- 接触成核是工业结晶的心脏：低过饱和可运行（品质好）、速率∝s 一次方（好控制）、叶轮碰撞性质决定成核量（设计杠杆=叶尖速度）。
- MSMPR 是 CSD 的"理想反应器"：ln n–L 直线的截距给 n°（→B°=Gn°）、斜率给 −1/Gτ；矩方程给出全套分布，z=3 即主导粒径。
- 设计配方：目标 L_pr→定 τ=L_pr/3G→由产量定 B°=9C/(2aρ_cV_cL_pr³)→校核设备能否在低 s 下维持该 G。
- 增大粒径两板斧：细晶消除+溶质循环（适高溶解度体系）、DDO 双出料（适任何体系，得双峰分布）。
- 焓-浓图（含固相）+重心原理=真空/冷却结晶器的全部衡算工具；绝热闪蒸时进料-蒸气-晶浆三点共线。
