## 核心概念与公式

### 筛分
- 单筛给出两个 unsized fraction（只知一个边界粒径）；筛组给出 sized fractions。
- 筛上物料衡算：$F = D + B$，$F x_F = D x_D + B x_B$，得 $D/F = (x_F - x_B)/(x_D - x_B)$，$B/F = (x_D - x_F)/(x_D - x_B)$。
  - F 进料、D 筛上溢流、B 筛下底流；x 为粗粒（oversize）质量分数。
- **筛效率**：$E_A = D x_D/(F x_F)$（按筛上物计），$E_B = B(1 - x_B)/[F(1 - x_F)]$（按筛下物计）。
- 容量与效率相互制约：最大容量近似正比于筛孔尺寸 $D_{pc}$；粒径小于 150 目（0.1 mm）后筛分困难。粗筛（6–100 mm）容量约 1–8 ton/h·ft²，1–6 mm 筛约 0.1–1.0 ton/h·ft²。
- 堵孔（blinding）：细长、黏、片状、软颗粒易楔入筛孔；振动筛（1800–3600 次/min）比回转筛不易堵。

### 滤饼过滤理论基础
- 总压降 = 滤饼压降 + 介质压降：$\Delta p = \Delta p_c + \Delta p_m$（式 29.7）。
- 滤饼内层流压降梯度（Kozeny 型，式 29.8）：
  $$\frac{dp}{dL} = \frac{150\,\mu u (1-\varepsilon)^2}{(\Phi_s D_p)^2 \varepsilon^3}$$
  其中 dp/dL 为滤饼内距介质 L 处的压力梯度，μ 滤液黏度，u 基于过滤面积的滤液表观流速，Φs 颗粒球形度，Dp 颗粒粒径，ε 滤饼空隙率。
- **比滤阻（specific cake resistance）**（式 29.14、29.15b）：
  $$\alpha \equiv \frac{\Delta p_c A}{\mu u m_c} = \frac{k_2 (1-\varepsilon)}{(\Phi_s D_p)^2 \varepsilon^3 \rho_p}$$
  α 为单位质量干滤饼的流动阻力（m/kg），mc 为滤饼中干固体总质量，ρp 颗粒密度。不可压缩滤饼 α 与压差无关。
- **介质阻力**：$R_m \equiv \Delta p_m / (\mu u)$（式 29.16），量纲 L⁻¹；通常只在一开始重要，近似取常数。
- 过滤基本方程（式 29.20）：$\frac{dt}{dV} = \frac{\mu}{A \Delta p}\left(\frac{\alpha c V}{A} + R_m\right)$，c 为单位体积滤液沉积的干固体质量（kg/m³）。
- **恒压过滤**（式 29.22–29.24）：$\frac{t}{V} = \frac{K_c}{2}V + \frac{1}{q_0}$，其中 $K_c = \frac{\mu c \alpha}{A^2 \Delta p}$。t/V 对 V 作图为直线，斜率 Kc/2、截距 1/q0 → 解出 α 与 Rm。
- **滤饼压缩性经验式**（式 29.25）：$\alpha = \alpha_0 (\Delta p)^s$，s 为压缩性系数：不可压缩 s = 0；通常 0.2–0.8。只能在实验压差范围内使用。
- **恒速过滤**（式 29.38）：$(\Delta p - \Delta p_m)^{1-s} = K_r t$，$K_r = \mu u^2 c \alpha_0$。
- **连续过滤**（转鼓类，Rm 可忽略，式 29.32–29.33）：
  $$\frac{\dot{m}_c}{A_T} = \left(\frac{2 c \Delta p^{1-s} f n}{\alpha_0 \mu}\right)^{1/2}$$
  $\dot m_c/A_T$ 为单位总过滤面积的产固速率，f 为转鼓浸没分数，n 为转速（r/s），tc 为周期。压差增大、转速提高（薄饼快转）均可提高产量；转速过高则饼湿且难卸料。
- **离心过滤**（式 29.42–29.44）：离心压差 $\Delta p = \rho \omega^2 (r_2^2 - r_1^2)/2$；流量
  $$q = \frac{\rho \omega^2 (r_2^2 - r_1^2)}{2 \mu (\alpha m_c/\bar{A}_L \bar{A}_a + R_m/A_2)}$$
  其中 $\bar A_a$ 为滤饼面积的算术平均、$\bar A_L$ 为对数平均（式 29.45–29.46）；同一物料在离心机中的 α 通常略高于压滤/真空过滤。
- **滤饼洗涤三阶段**：①置换洗涤（displacement wash，条件好时可回收滤饼内约 90% 溶质，所需洗水量≈饼内存留滤液量 εAL）；②浓度快速下降段（洗水量与第一阶段同量级）；③残余溶质缓慢浸出段。洗涤速率近似等于末期过滤速率（黏度差需校正）；多孔颗粒内的溶质需先扩散到表面，行为类似固定床穿透曲线（可用 Ch.25 方程）。

### 澄清过滤
- 介质孔径大于颗粒，颗粒被截留在介质内部或表面（clarification ≠ screening）。
- 碰撞（impingement）捕集：**靶效率** ηt = 撞击靶面的颗粒分数；**分离数** $N_s = u_t u_0/(g D_b)$（ut 颗粒终端沉降速度、u0 来流速度、Db 靶宽或直径）。Stokes 区 ut ∝ Dp²：粒径越小 ηt 越低，但减小靶径可提高 ηt——故用细纤维深床反复拦截；极细雾滴（~0.1 μm）靠布朗扩散反而 ηt 随粒径减小而升高。
- 袋式除尘器效率可达 99%，远细于布的孔径，靠介质内截留。

### 错流过滤与膜滤（微滤/超滤）
- 尺寸范围：微滤 0.5–5 μm 颗粒；超滤 0.5 μm 至约 10⁻³ μm（M ≈ 300）以上大分子；反渗透按溶解-扩散机制分离小分子/离子（Ch.26）。
- 修正 Hagen–Poiseuille 通量式（式 29.47）：
  $$v = \frac{(\Delta p - \Delta \pi) D^2 \varepsilon}{32 L \tau \mu}$$
  v 为渗透液表观流速，D 平均孔径，ε 孔隙率，L 表皮层厚度，τ 曲折因子。工程上用**膜渗透性** Qm（纯水通量/压差）表征：$v = Q_m(\Delta p - \Delta \pi)\,\mu_{\mathrm{H_2O}}/\mu$（式 29.49）。
- **浓差极化**（式 29.50–29.52）：边界层内 $v c + D_v\,dc/dx = v c_2$；积分得 $\ln\frac{c_s - c_2}{c_1 - c_2} = \frac{v}{k_c}$；完全截留（c2 = 0）时
  $$v = k_c \ln\frac{c_s}{c_1}$$
  cs 膜面浓度、c1 主体浓度、kc 传质系数。压差升高时通量先近线性增加，随后因 cs 达到凝胶浓度 cg（凝胶层阻力控制）而达到**极限通量**——不再随 Δp 增大。蛋白质 cg 约 10–50 wt%，胶乳约 70 wt%；低分子量蛋白浓差极化可使过半驱动力消耗于渗透压差。
- **部分截留**（式 29.57–29.61）：局部截留率 $R \equiv 1 - c_2/c_1$；忽略膜内扩散时
  $$\frac{1-R}{R} = \frac{K}{1-K}\exp\frac{v}{k_c}$$
  K 为分配系数（圆柱孔/球形分子 K = (1-λ)²，λ 分子/孔径比）。v→0 时 R → 1-K；通量越大、浓差极化越强，R 越低。计入膜内分子扩散（式 29.62–29.64）后，R 随通量先升后降存在极大值（vL/De < 2 时扩散显著）。
- 膜污染：孔口堵塞、孔壁吸附、表面沉积/凝胶压缩；通量随时间下降（截留率常反升）。对策：改变 pH、低压运行、反冲洗、化学清洗。
- **胶体悬浮液的 flux paradox**：胶体（如 0.2 μm 胶乳）极限通量比蛋白高 2–5 倍，尽管其正常扩散系数低一个量级。解释为**剪切诱导扩散**（式 29.65）：$D_s = 0.03\,\gamma r^2$（γ 壁面剪切率，r 颗粒半径），Ds ∝ γ·r²。
- 分子扩散系数（Stokes–Einstein，式 29.53–29.56）：$D_v = \mathbf{k}T/(6\pi r_0 \mu) = 7.32\times10^{-16}T/(r_0 \mu')$；蛋白质半径 $r_0 = 6.57\times10^{-9}M^{1/3}$（ρp = 1.4 g/cm³）；无规线团聚合物取回转半径（2–3 倍摩尔体积半径）。
- 设备要点：管式膜（内径 5–25 mm，1–5 m/s 湍流）、中空纤维（0.2–2 mm，层流高剪）、卷式（入口缝约 1 mm）；无机（Al₂O₃/ZrO₂）膜耐高温、耐化学清洗。经验关联式（层流/湍流传质）预测极限通量与实验偏差约 ±30%。

### 重力沉降
- 澄清器（clarifier，几乎全部除去颗粒）与分级机（classifier，按粒径/密度分成两个粒级）原理同为沉降。
- **分选分级机**：①重介质法（sink-and-float，介质密度介于轻重物料之间，分离原则上与粒径无关；介质用磁铁矿 ρ=5.17、铁硅合金 6.3–7.0、方铅矿 7.5 的水悬浮液，处理 >10 目粗粒，可分辨比重差仅 0.1 的物料）；②差速沉降法（differential settling，受粒径-密度交叉干扰）。
- **等沉降颗粒**（equal-settling particles）：Stokes 区 $\frac{D_{pA}}{D_{pB}} = \sqrt{\frac{\rho_{pB}-\rho}{\rho_{pA}-\rho}}$，Newton 区比值降为一次方（式 29.68–29.69）；提高介质密度或缩窄进料粒径范围可减少混合级分。
- 批式沉降分区：A 清液区、B 等浓度（自由/受阻）区、C 过渡区、D 压实区；清液-悬浮界面下降曲线：恒速段→降速段→压实终止。
- **增浓器（thickener）设计**（式 29.70–29.71）：总固体通量 $G = G_t + G_s = u c + \frac{dZ}{dt}c$（输送通量+沉降通量）；设计面积
  $$A = \frac{F c_0}{(G_t + G_s)_{\min}}$$
  取总通量曲线最低点对应浓度层控制。确定 Gs 用批式沉降实验：Coe–Clevenger 法（多浓度初始速率）或 Kynch 法（单条曲线切线，截距 Zi，c = c0Z0/Zi）。增大底流流速可减小面积但降低底流浓度。澄清能力主要取决于面积而非深度。大型增浓器直径 10–100 m、深 2.5–3.5 m。

### 旋风分离器与水力旋流器
- **分离因子**（式 29.72）：$F_c/F_g = u_{\tan}^2/(r g)$。0.3 m 旋风、壁速 15 m/s 时约 155；小旋风可达 2500。切向速度 >15–20 m/s 不实际（压降、磨损大）；大流量用多台小旋风并联。
- 效率随粒径、颗粒密度、流量增大而升高；随气温升高（气体黏度增大）而降低；理论 Dp² 依赖被细粉团聚部分掩盖。压降 ∝ ρu²，与固体密度无关，且随含尘浓度增大反而略降。旋风是少见的"满载优于部分负载"的分离设备。第二级效率低于第一级（进料平均粒径已变小）。
- **水力旋流器（hydroclone）**：以分级为主。增浓用途要求底流 <12 vol%（否则牺牲澄清）；分级用途底流最高约 50 vol%。切割粒径 ∝ D_c^{1.5}·Δp^{-0.25}（稀进料）——切割粒径对压降弱敏感，大压差不经济；直径越小分离越好，故机器小（10 mm–1.2 m），大型装置并联多至 480 台。压降 ∝ 流量^{2.0–3.3}。

### 离心沉降
- 机器类型：管式（bowl φ100–150 mm，~15,000 rpm）、碟片式（φ200–500 mm，4,000–6,500 rpm，碟片缩短沉降距离并剪切破乳，适于乳浊液浓缩如奶油分离）、喷嘴排渣式（含固 >几% 连续排渣）、螺旋输送式（scroll，φ100–1,400 mm，450 mm 机型可处理 1–2 ton 固/h）、轴流输送式（无螺旋扰动段+纵向叶片，Σ 提高 3–4 倍）。
- **切割直径理论**（Stokes 区，式 29.73–29.76）：粒子以终端速度径向沉降、停留时间 tT = V/q；$q_c = \frac{\pi b \omega^2 (\rho_p - \rho) D_{pc}^2}{18\mu}\cdot\frac{r_2^2 - r_1^2}{\ln[2 r_2/(r_1 + r_2)]}$（cut point：恰好沉降一半液层厚度的颗粒）。薄液层近似（式 29.80）：$q_c = 2 V u_t/s$。
- **Σ 理论与放大**（式 29.81）：$q = 2 \Sigma u_g$，其中
  $$\Sigma = \frac{2 V \omega^2 r_e}{g s_e}$$
  Σ 等效于"与该离心机同分离能力的重力沉降槽横截面积"，ug 为重力场终端沉降速度。放大时同类型机器 Σ 之比即流量之比。典型值：19.5 in 碟片机 Σ ≈ 1.05×10⁷ ft²（相当于 10⁵ m² 重力沉降面积）；管式机 2.7×10⁴ ft²。实际容量常低于 Σ 预测（内部流场复杂、输送器再悬浮）。
- 轴流输送离心机模型（Schnittger）：分离发生在薄边界层内，一旦沉入池中即算去除；全螺旋机边界层比轴流机厚约 10 倍且螺旋流引起湍流阻碍沉降。
- 离心分级：600 g 以上离心力可尖锐分离 1 μm 以下颗粒；离心力不改变化学，但可改变沉降流态（Stokes→Newton），弱絮体在离心机中可能被打散反而难沉降。

## 经验规则与决策要点
- **筛分**：容量与效率互相抵消，<150 目筛分不经济应改用其他方法；效率取 E_A、E_B 中较低者作保守评估。
- **过滤机选型**：压力滤机适合细颗粒/黏液（压差大但间歇）；真空转鼓适合中等速率大规模连续（压差仅 250–500 mmHg）；粗颗粒快速沉降料浆选顶给料水平带式；胶体/糊状细渣用预涂层转鼓（50% 浸没、刀片缓进）。离心过滤机产出比真空过滤"更干"的饼，若后续热干燥可显著省能。
- **过滤面积放大**：实验恒压 t/V-V 直线 → α(Δp)、Rm → 代入连续过滤式（含 s 的式 29.33）算面积；压差对产量的贡献被 α~Δp^s 部分抵消（有效 Δp^{(1-s)/2}）。
- **压滤机洗涤差**：洗涤液短路使厚饼难洗净；要求极好洗涤时改再浆化重滤或叶滤机。
- **UF 操作点**：通常运行在极限通量附近（Δp 仅 1–5 atm 即达限），盲目加压只增凝胶层厚度；提高通量靠提高流速/剪切（kc ∝ u^0.9）而非加压。膜堵 5 倍后极限通量不变，只是达到同一通量所需压差升高。
- **离心放大**：先算 ug（重力终端速度）再匹配 Σ；同类机型 q ∝ Σ。切割粒径弱依赖压差（Δp^{-0.25}），优先选小直径多管并联。

## 典型例题
- **例 29.1**：CaCO₃ 恒压过滤（5 组 Δp）：t/V–V 直线求 Kc、q0 → α、Rm；对数作图得压缩性式 α = 2.90×10¹⁰ Δp^0.26（Rm 随 Δp 近线性增但增幅有限）。
- **例 29.2**：转鼓真空过滤设计：给定 30% 浸没、Δp = 20 inHg、周期 5 min、湿基 50% 水分滤饼，由式 29.33 反算所需总过滤面积 81.7 ft²（含 c 的换算与产固速率 0.302 lb/s 的物料衡算）。
- **例 29.3**：超滤干酪乳清（管式膜、Re = 30,000）：Sh–Re–Sc 关联求 kc，试差求 v–Δp 曲线；结果 c1 = 10 g/L 时浓差极化使表面浓度 3.6 倍、渗透压差吃掉过半驱动力；极限通量 104 L/m²·h（cg = 400 g/L）；膜堵 5 倍仅使低压区通量降约 30%。
- **例 29.4**：UF 部分截留：由一组 (v, R) 反求 K = 0.101，预测更低通量下 R = 0.84、Rmax = 1-K = 0.90；对 M = 10,000 低分子级分用 K = (1-λ)² 与 kc 换算估算 R ≈ 0.52——分子量仅差 3 倍时无法尖锐分级；膜内扩散项 vL/De ≈ 0.45 不可忽略。

## 记忆钩子
- 恒压过滤一条直线定两参数：t/V vs V → 斜率给滤饼、截距给介质。
- UF 通量公式串：V–L–μ（孔模型）→ Qm → 浓差极化 ln(cs/c1) → 极限通量 kc·ln(cg/c1)。
- 旋风与旋流器共享 u²/r 离心力逻辑；分离因子 ~10²–10³，Σ 理论把离心机折算成多大面积的重力沉降槽。
