# Glossary — 关键术语速查

按篇章分组；符号保留原书记法。详细用法见对应章节文件。

## Section I–II 导论与流体力学（ch1–9）

- **量纲分析 dimensional analysis**（ch1）：用无因次数群（Re、Eu、Fr…）归并变量，把多变量问题压缩成关联式。
- **压差计 manometer**（ch2）：U 形管读数 $\Delta p = (\rho_A - \rho_B)gR$。
- **离心中性区 neutral zone**（ch2）：旋转液体内压强与重力平衡的等压面区域，离心沉降的分离极限。
- **Newton 黏性定律**（ch3）：$\tau = \mu\,du/dy$，动量顺速度梯度传递。
- **雷诺数 $N_{Re} = D\bar V\rho/\mu$**（ch3）：惯性/黏性之比，流态判据。
- **湍流应力/涡流黏度 $\eta$**（ch3）：湍流脉动引起的附加动量通量。
- **边界层 boundary layer**（ch3/7/12）：壁面近旁速度（或温度、浓度）梯度集中的薄层。
- **Bernoulli 工作式**（ch4）：$\Delta(zg/\alpha g_c + \bar V^2\beta/2g_c + p/\rho) + \Sigma h_f = \eta W_p$，湍流时 α、β≈1。
- **Fanning 摩擦系数 $f$**（ch5）：$f = \tau_w/(\rho\bar V^2/2)$，沿程阻力归一化。
- **水力半径 $r_H = S/L_p$**（ch5）：非圆截面等效化桥梁（圆管 $r_H = D/4$）。
- **摩擦速度 $u^* = \bar V\sqrt{f/2}$**（ch5）：湍流分层标尺。
- **普遍速度分布 $u^+$–$y^+$**（ch5）：层流底层/缓冲区/湍流核心三段对数律。
- **水力粗糙度 $k/D$**（ch5）：壁面凸起对 $f$ 的影响参数。
- **局部损失系数 K**（ch5）：突扩 $K_e=(1-S_a/S_b)^2$、突缩 $K_c=0.4(1-S_b/S_a)$。
- **声速 $a=\sqrt{\gamma p/\rho}$、马赫数 Ma**（ch6）：可压缩流分类标尺。
- **临界压比 $r_c = (2/(\gamma+1))^{\gamma/(\gamma-1)}$**（ch6）：γ=1.4 时 0.528，壅塞判据。
- **滞止温度 $T_s = T + u^2/2c_p$**（ch6）：绝热流守恒量。
- **Fanno 流**（ch6）：绝热+摩擦，Ma→1 不可穿越。
- **曳力系数 $C_D$**（ch7）：绕流阻力归一化，管流 $f$ 的对应物。
- **Stokes 定律**（ch7）：$Re_p<1$ 爬流区 $C_D=24/Re_p$。
- **球形度 $\Phi_s$**（ch7）：非球形颗粒比表面修正（破碎料 0.6–0.8）。
- **Ergun 方程**（ch7）：固定床压降 = 层流 150 项 + 湍流 1.75 项。
- **最小流化速度 $\bar V_{0M}$**（ch7）：床压降 = 单位面积床重。
- **干涉沉降 $u_s = u_t\varepsilon^n$**（ch7）：Maude–Whitmore 浓悬浮修正。
- **扬程 $\Delta H$、NPSH**（ch8）：泵机械能增量；防气蚀的吸入余量。
- **Euler 叶轮方程 $\Delta H_e = u_2 V_{u2}/g$**（ch8）：离心泵动量传递。
- **相似定律**（ch8）：$q\propto n$、$\Delta H\propto n^2$、$P\propto n^3$。
- **膨胀因子 Y**（ch8）：可压缩流体孔板/文丘里流量修正。
- **孔板系数 $C_o \approx 0.61$**（ch8）：缩流+摩擦+速度分布的合成修正。
- **功率数 $N_P = P/(n^3D_a^5\rho)$**（ch9）：叶轮功率无量纲表征，湍流区趋于常数。
- **流动数 $N_Q$、混合时间指数 $nt_T$**（ch9）：循环能力与混匀速度。
- **Zwietering 临界转速 $n_c$**（ch9）：颗粒完全悬浮的最低转速。
- **Sauter 平均直径 $\bar D_s = 6\Psi/a$**（ch9）：液滴体系比表面定义直径。

## Section III 传热（ch10–16）

- **热扩散率 $\alpha = k/\rho c_p$**（ch10）：温度扰动传播速率。
- **对数平均半径/面积 $\bar r_L$**（ch10）：圆筒壁导热的等效面积；$r_o/r_i<1.4$ 才可用算术平均。
- **Fourier 数 $Fo = \alpha t/s^2$**（ch10）：非稳态导热无量纲时间。
- **Biot 数 $Bi = hs/k$**（ch10）：外阻/内阻比，选解判据。
- **穿透距离 $x_p = 3.64\sqrt{\alpha t}$**（ch10）：半无限固体热扰动深度。
- **接触热阻**（ch10）：典型 ~0.088 °C·m²/W。
- **LMTD $\overline{\Delta T_L}$**（ch11）：对数平均温差推动力。
- **总传热系数 U**（ch11）：阻力串联合成，面积基准必须声明。
- **污垢系数 $h_d$**（ch11）：附加热阻兼设计裕量。
- **控制阻力**（ch11）：分系数最小的一侧，$U\approx h_{\min}$。
- **Pr 数 $c_p\mu/k$**（ch12）：热/动量边界层厚度比。
- **Graetz 数 $Gz = \dot m c_p/kL$**（ch12）：管内层流入口区判据。
- **Colburn $j_H = St\cdot Pr^{2/3}\phi_v$**（ch12）：三传类比桥梁，$j_H = f/2$。
- **黏度修正 $\phi_v = (\mu/\mu_w)^{0.14}$**（ch12）：加热/冷却不对称。
- **Grashof 数 $Gr$**（ch12）：自然对流判据。
- **Sieder–Tate / Dittus–Boelter**（ch12）：湍流管内传热两条关联式。
- **膜状/滴状冷凝**（ch13）：设计按膜状（滴状 h 高 5–8 倍但不可靠）。
- **冷凝液负荷 $\Gamma$**（ch13）：$Re = 4\Gamma/\mu_f$ 定冷凝流态。
- **临界温差 $\Delta T_c$**（ch13）：泡核→过渡沸腾转折，越过则 h 与 q 同降。
- **峰值热流 (q/A)_max / Zuber 式**（ch13）：沸腾设计红线。
- **Leidenfrost 点**（ch13）：稳定气膜起点。
- **黑体/发射率 $\varepsilon$**（ch14）：理想/实际发射体的功率比。
- **视角因子 $F_{12}$**（ch14）：几何路由份额，$A_1F_{12}=A_2F_{21}$ 互换。
- **灰体互换因子 $\mathcal{F}$**（ch14）：发射率+几何联合修正。
- **Wien 位移律、Kirchhoff 定律**（ch14）：$T\lambda_{max}=2890$ μm·K；$\varepsilon=\alpha$。
- **遮热屏**（ch14）：每加一层热流约减半。
- **1-2 / 2-4 壳管式**（ch15）：管程/壳程数；多程换 h 也换压降。
- **LMTD 修正因子 $F_G$**（ch15）：多程偏离纯逆流的折减，<0.75 改设计。
- **传热单元数 $N_H = UA/\dot m c_p$**（ch15）：ε–N_H 法不定温差定出口温度。
- **翅片效率 $\eta_F$**（ch15）：扩展表面有效性，气侧必用。
- **economy（经济容量）**（ch16）：kg 蒸发水/kg 生蒸汽。
- **BPE 沸点升高**（ch16）：溶质造成的额外温差损失（Dühring 线求值）。
- **升膜/降膜/强制循环蒸发器**（ch16）：自然循环、分布器控制、抗结垢三种路线。
- **多效等面积条件**（ch16）：$A_1U_1\Delta T_1 \approx A_2U_2\Delta T_2\cdots$，ΔT 与 U 成反比分配。
- **MVR 机械蒸汽再压缩**（ch16）：二次汽升压回用，economy 相当 10–15 效。

## Section IV 传质与分离（ch17–27）

- **等摩尔扩散 / 单向扩散**（ch17）：蒸馏（线性梯度）vs 吸收（对数梯度，通量放大 $1/(1-y_A)_L$）。
- **Schmidt 数 $Sc = \nu/D_v$**（ch17）：气体 0.5–2，液体 10²–10⁵。
- **渗透理论**（ch17）：短接触界面 $\bar k_c = 1.13\sqrt{D_v/t_T}$，k∝D^½。
- **两膜理论**（ch17）：$1/K_y = m/k_x + 1/k_y$，界面平衡。
- **Chilton–Colburn 类比**（ch17）：$j_M = j_H = f/2$。
- **Froessling 式 $Sh = 2 + 0.6Re^{1/2}Sc^{1/3}$**（ch17）：单球绕流，Sh→2 是下限。
- **填料因子 $F_p$ / $f_p$**（ch18）：压降/传质性能的填料特征数。
- **HTU / NTU**（ch18）：$N_{Oy}=\int dy/(y-y^*)$；$H_{Oy} = H_y + (mG_M/L_M)H_x$。
- **载点/液泛**（ch18）：填料塔水力学上限。
- **增强因子 $\phi$**（ch18）：化学吸收速率倍数（1–1000+）。
- **湿度 $H$、绝热饱和温度 $T_s$、湿球温度 $T_w$**（ch19）：湿气体的三把尺子。
- **Lewis 关系**（ch19）：$h_y/(M_Bk_y)\cong c_s$，仅空气-水 $T_w=T_s$。
- **凉水塔逼近度 approach**（ch19）：出水温−湿球温，设计 5–15°F。
- **理论级**（ch20）：离开两相互成平衡的级。
- **夹紧 pinch**（ch20）：操作线触平衡线，推动力归零。
- **吸收因子 $A = L/mV$ / 汽提因子 $S = mV/L$**（ch20）：级联解析的统一参数。
- **Kremser 方程**（ch20）：恒 A/S 级联的解析解。
- **恒摩尔溢流**（ch21）：潜热近似相等，操作线为直线的前提。
- **回流比 $R_D$、q 线**（ch21）：精馏两大设计旋钮。
- **Fenske / Gilliland**（ch21/22）：$N_{\min}$（全回流）与 N–R_D 内插。
- **关键组分 LK/HK**（ch22）：定义分离任务的相邻挥发序组分。
- **Underwood 法**（ch22）：多组分 $R_{Dm}$ 的根试差群法。
- **底流/溢流**（ch23）：固体持液 L 与级间溶液 V，决定浸取操作线。
- **萃取因子 $E = K_DV/L$**（ch23）：浸取/萃取的 Kremser 参数。
- **褶点 plait point**（ch23）：三元相图共轭两相趋同点。
- **自由水分 / 结合水**（ch24）：干燥计算的有效水分 vs 束缚水分。
- **临界湿含量 $X_c$**（ch24）：恒速段终点，非纯物性。
- **恒速段速率 $R_c = h_y(T-T_{wb})/\lambda$**（ch24）：界面=湿球温度。
- **穿透曲线 / LUB**（ch25）：固定床出口 S 形曲线与未利用床层当量长度。
- **传质单元数 $N = K_caL/u_0$**（ch25）：穿透陡峭度。
- **分离因子 α**（ch25）：色谱/离子交换平衡比。
- **PSA 变压吸附**（ch25）：热敏组分的压降再生。
- **渗透系数 $Q_A = D_A\cdot S_A$**（ch26）：溶解扩散"扩散×溶解"组合量。
- **选择性 $\alpha = Q_A/Q_B$**（ch26）：膜分离核心指标。
- **渗透汽化**（ch26）：破坏共沸专用，跨膜活度驱动。
- **浓差极化比 $\Gamma = J_wf/k_c$**（ch26）：>0.1 不可忽略。
- **stage cut**（ch26）：渗透侧抽出率，影响实际选择性。
- **过饱和度 $s$**（ch27）：结晶驱动力，工业控制 <1.02–1.05。
- **次级成核**（ch27）：流体剪切与晶体接触成核，工业主体。
- **ΔL 定律**（ch27）：$G$ 与粒径无关时 $\Delta L = G\Delta t$。
- **总体密度 n / MSMPR**（ch27）：$n = n^\circ e^{-z}$，粒度分布完全解。
- **主导粒径 $L_{pr} = 3G\tau$**（ch27）：MSMPR 产品的体积主导粒径。
- **细晶消除 fines destruction**（ch27）：停留时间差制提升平均粒径。

## Section V 颗粒固体（ch28–29）

- **比表面平均粒径 $\bar D_s$ / 质量平均 $\bar D_w$**（ch28）：表面积敏感过程 vs 粉碎能耗各用各的平均。
- **Bond 定律与功指数 $W_i$**（ch28）：粉碎能耗经验律，kWh/ton。
- **休止角 $\alpha_r$**（ch28）：15–30°，散体流动性直观指标。
- **Jenike 质量流/漏斗流**（ch28）：仓斗流型设计与防 rathole。
- **临界转速 $n_c$**（ch28）：球磨操作取 65–80% $n_c$。
- **比滤阻 $\alpha = \alpha_0(\Delta p)^s$**（ch29）：滤饼过滤放大核心数据。
- **压缩性系数 s**（ch29）：0.2–0.8，滤饼可压缩性。
- **Σ 等效沉降面积**（ch29）：离心机放大参数，$q = 2\Sigma u_g$。
- **分离因子 $u^2_{tan}/(rg)$**（ch29）：旋流/离心的离心场强度（典型 155–2500）。
- **极限通量 / 凝胶层**（ch29）：UF 中 $v_{max} = k_c\ln(c_g/c_1)$，压差无效区。
- **碰撞分离数 $N_s$**（ch29）：惯性捕集靶效率判据。
